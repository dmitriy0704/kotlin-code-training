# Задача 1

## Условие

Дан массив чисел a_1, a_2, ..., a_n.
Необходимо найти монотонный подотрезок (то есть строго убывающий или строго
возрастающий) максимальной длины и вернуть пару индексов его начала и конца.

```text
Примеры:
[2, 7, 5, 4, 4, 3] -> {1, 3}
[1, 1] -> {1, 1} // or {0, 0}
```

## Решение

Эта задача эффективно решается за один проход по массиву (линейное время $O(n)$)
с использованием метода двух указателей (или динамического программирования «на
лету»).
Так как в примерах для массива [2, 7, 5, 4, 4, 3] результатом является {1, 3} (
элементы 7, 5, 4 — строго убывающий подотрезок), мы видим, что используется
0-индексация (индексы 1, 2, 3). Для массива [1, 1] ответом будет {0, 0} (или {1,
1}, если вы хотите 1-индексацию, но ниже в коде мы используем стандартную для
Kotlin 0-индексацию).

## Алгоритм решения

1. Если массив пустой, возвращаем пару (-1, -1). Если из одного элемента — (0,
   0).
2. Мы поддерживаем текущую длину возрастающего и убывающего подотрезков.
3. Идем по массиву с 1-го элемента (индекс 1) до конца:

* Если a[i] > a[i-1], то возрастающий отрезок продолжается, а убывающий
  сбрасывается (его длина становится равной 1, а начало смещается в i).
    * Если a[i] < a[i-1], то убывающий отрезок продолжается, а возрастающий
      сбрасывается.
    * Если a[i] == a[i-1], то оба отрезка сбрасываются до длины 1, так как нам
      нужна строгая монотонность.

4. На каждом шаге проверяем, превышает ли длина текущего отрезка максимальную
   найденную. Если да — обновляем глобальные индексы начала и конца.

## Код на Kotlin

```kotlin
fun findMaxMonotonicSubarray(a: IntArray): Pair<Int, Int> {
    if (a.isEmpty()) return Pair(-1, -1)
    if (a.size == 1) return Pair(0, 0)

    // Глобальные переменные для хранения лучшего ответа
    var maxStart = 0
    var maxEnd = 0
    var maxLength = 1

    // Текущие указатели для возрастающего подотрезка
    var incStart = 0
    // Текущие указатели для убывающего подотрезка
    var decStart = 0

    for (i in 1 until a.size) {
        if (a[i] > a[i - 1]) {
            // Строгое возрастание продолжается, убывание сбрасывается
            decStart = i
        } else if (a[i] < a[i - 1]) {
            // Строгое убывание продолжается, возрастание сбрасывается
            incStart = i
        } else {
            // Элементы равны, оба тренда прерываются
            incStart = i
            decStart = i
        }

        // Вычисляем текущие длины
        val currentIncLength = i - incStart + 1
        val currentDecLength = i - decStart + 1

        // Проверяем, обновился ли максимум для возрастания
        if (currentIncLength > maxLength) {
            maxLength = currentIncLength
            maxStart = incStart
            maxEnd = i
        }

        // Проверяем, обновился ли максимум для убывания
        if (currentDecLength > maxLength) {
            maxLength = currentDecLength
            maxStart = decStart
            maxEnd = i
        }
    }

    return Pair(maxStart, maxEnd)

}
fun main() {
// Тест 1
    val arr1 = intArrayOf(2, 7, 5, 4, 4, 3)
    println(findMaxMonotonicSubarray(arr1)) // Выведет: (1, 3) -> элементы 7, 5, 4

    // Тест 2
    val arr2 = intArrayOf(1, 1)
    println(findMaxMonotonicSubarray(arr2)) // Выведет: (0, 0)

    // Тест 3 (Возрастание)
    val arr3 = intArrayOf(1, 3, 5, 2, 4)
    println(findMaxMonotonicSubarray(arr3)) // Выведет: (0, 2) -> элементы 1, 3, 5

}

```


## Сложность:

* По времени: $O(n)$ — массив обходится ровно один раз.
* По памяти: $O(1)$ — используется фиксированное количество переменных для
  хранения индексов.
