# 1. Two Sum

## Условие

Дан массив целых чисел nums и целое число target. Необходимо вернуть индексы
этих двух чисел, сумма которых равна target.

Можно предположить, что для каждого входного параметра существует ровно одно
решение, и нельзя использовать один и тот же элемент дважды.

Вы можете вернуть ответ в любом порядке.

Example 1:

Input: nums = [2,7,11,15], target = 9
Output: [0,1]
Explanation: Because nums[0] + nums[1] == 9, we return [0, 1].

## Решение


### Условие

Дан массив целых чисел `nums` и целое число `target`. Вернуть **индексы** двух
чисел, которые в сумме дают `target`.  
Предполагается, что решение существует ровно одно, и один и тот же элемент
нельзя использовать дважды.  
Порядок индексов не важен.

### Идея решения (O(n) по времени, O(n) по памяти)

Используем **хеш-таблицу (HashMap)**, чтобы запоминать для каждого числа его
индекс.  
Проходим по массиву один раз. Для текущего элемента `num` вычисляем
`complement = target - num`.  
Если `complement` уже есть в карте — значит, мы нашли пару: индекс
`complement` (из карты) и текущий индекс.  
Если нет — сохраняем `num` и его индекс в карту для будущих проверок.

**Почему это работает быстро?**

- Поиск в `HashMap` в среднем занимает O(1).
- Мы проходим массив ровно один раз → O(n).

**Важный момент:** мы добавляем элемент в карту **после** проверки. Это
гарантирует, что мы не используем один и тот же индекс дважды. Если бы мы
добавляли до проверки, то для случая `target = 2 * num` (например,
`nums = [3, 3]`, `target = 6`) мы бы нашли индекс самого себя.

### Код на Kotlin

```kotlin
class Solution {
    fun twoSum(nums: IntArray, target: Int): IntArray {
        // Храним число → его индекс
        val map = mutableMapOf<Int, Int>()

        for ((index, num) in nums.withIndex()) {
            val complement = target - num
            // Если дополнение уже есть в карте — нашли решение
            if (map.containsKey(complement)) {
                return intArrayOf(map[complement]!!, index)
            }
            // Иначе запоминаем текущее число и его индекс
            map[num] = index
        }
        // По условию решение всегда есть, сюда не дойдём
        return intArrayOf()
    }
}
```

### Пояснение к коду

- `withIndex()` даёт нам пару `(index, value)`.
- `map[complement]!!` — оператор `!!` безопасен, потому что мы только что
  проверили наличие ключа через `containsKey`.
- Сложность: O(n) по времени, O(n) по памяти (в худшем случае храним все
  элементы).


### Альтернативный вариант (без `withIndex`)

```kotlin
fun twoSum(nums: IntArray, target: Int): IntArray {
    val map = mutableMapOf<Int, Int>()
    for (i in nums.indices) {
        val complement = target - nums[i]
        if (map.containsKey(complement)) {
            return intArrayOf(map[complement]!!, i)
        }
        map[nums[i]] = i
    }
    return intArrayOf()
}
```


### Проверка на примере

`nums = [2, 7, 11, 15]`, `target = 9`

- i=0, num=2, complement=7 → карта пуста, добавляем {2→0}
- i=1, num=7, complement=2 → 2 есть в карте, возвращаем [0, 1] → верно.


### Что ещё можно учесть

- Если массив очень большой, но диапазон чисел ограничен, можно использовать
  массив вместо `HashMap` для ускорения, но в общем случае `HashMap`
  универсален.
- Kotlin предлагает функцию `getOrElse` или `getOrDefault`, но здесь проверка
  через `containsKey` читается понятнее.

Разберём по шагам на вашем примере:

- Массив: `[2, 7, 12, 13, 14]`, `target = 9`
- Начинаем с индекса `0` (значение = `2`):
    - `complement = 9 - 2 = 7`
    - Проверяем, есть ли `7` в `map` – пока нет.
    - **Сохраняем** в `map`: ключ = `2`, значение = `0` (индекс текущего
      элемента).  
      *(Вы написали `value = 1`, но это опечатка – на самом деле индекс `0`)*

- Переходим к индексу `1` (значение = `7`):
    - `complement = 9 - 7 = 2`
    - Проверяем, есть ли `2` в `map` – **да**, он там лежит с индексом `0`.
    - Значит, нашли пару: `map[2] == 0` и текущий индекс `1`.
    - Возвращаем `[0, 1]` – это и есть ответ.


**Важный нюанс:** мы **сначала** проверяем наличие дополнения, **потом**
добавляем текущий элемент. Это гарантирует, что мы не используем один и тот же
элемент дважды (например, если `target = 4`, а массив `[2, 2]` – тогда на втором
шаге найдём `2` из первого элемента, и ответ будет `[0, 1]`, что корректно).
