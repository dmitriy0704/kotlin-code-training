# 242. Valid Anagram

## Условие

Даны две строки s и t. Верните true, если t является анаграммой строки s, и
false в противном случае.

Example 1:
Input: s = "anagram", t = "nagaram"
Output: true

Example 2:
Input: s = "rat", t = "car"
Output: false

Constraints:

1 <= s.length, t.length <= 5 * 104
Буквы s и t представляют собой строчные английские буквы.

## Решение

## Задача 242. Valid Anagram (LeetCode)

**Условие:**  
Даны две строки `s` и `t`. Нужно вернуть `true`, если `t` является анаграммой
`s` (т.е. содержит те же символы в тех же количествах, но порядок может быть
любым).

---

### Решение 1. С использованием хеш-таблицы (HashMap)

Мы подсчитываем частоту каждого символа в `s`, а затем проходим по `t` и
уменьшаем эти частоты. Если в конце все частоты стали нулевыми, и не было
отрицательных значений – это анаграмма.

**Алгоритм:**

1. Если длины строк не равны → сразу `false`.
2. Создаём `Map<Char, Int>` и заполняем его: для каждого символа из `s`
   увеличиваем счётчик.
3. Проходим по символам `t`:
    - Если символа нет в карте или его счётчик уже равен 0 → `false`.
    - Иначе уменьшаем счётчик на 1.
4. После обработки всех символов `t` можно проверить, что все значения в карте
   равны 0 (или просто вернуть `true`, потому что длины равны и мы не нарушили
   условия, но лучше проверить).

**Код на Kotlin:**

```kotlin
fun isAnagram(s: String, t: String): Boolean {
    if (s.length != t.length) return false

    val charCount = mutableMapOf<Char, Int>()

    // Подсчёт частот в s
    for (ch in s) {
        charCount[ch] = charCount.getOrDefault(ch, 0) + 1
    }

    // Проход по t и уменьшение счётчиков
    for (ch in t) {
        val count = charCount.getOrDefault(ch, 0)
        if (count == 0) return false
        charCount[ch] = count - 1
    }

    // Можно проверить, что все значения стали нулевыми
    // (но если длины равны и мы не вернули false на предыдущем шаге, это гарантировано)
    return true
}
```

**Сложность:** O(n) по времени, O(1) по памяти (максимум 26 или 128 символов,
константа, но в общем случае O(k), где k – размер алфавита).

### Решение 2. С использованием массива размером 26 (для английских букв)

Поскольку по условию задачи строки содержат только строчные латинские буквы (это
обычно подразумевается, хотя в условии LeetCode явно не сказано, но в тестах
так), можно использовать массив из 26 целых чисел, что ещё быстрее и экономнее.

```kotlin
fun isAnagram(s: String, t: String): Boolean {
    if (s.length != t.length) return false

    val counts = IntArray(26)
    for (ch in s) {
        counts[ch - 'a']++
    }
    for (ch in t) {
        counts[ch - 'a']--
    }
    // Проверяем, что все нули
    for (count in counts) {
        if (count != 0) return false
    }
    return true
}
```

**Сложность:** O(n), память O(1) (массив фиксированного размера).

### Решение 3. Сортировка

Можно отсортировать обе строки и сравнить их.

```kotlin
fun isAnagram(s: String, t: String): Boolean {
    if (s.length != t.length) return false
    return s.toCharArray().sorted() == t.toCharArray().sorted()
}
```

**Сложность:** O(n log n) по времени, O(n) по памяти (для копий).

---

### Какой способ выбрать?

- Если важна производительность и память → массив или HashMap.
- Если хотите просто и лаконично → сортировка (часто принимается на LeetCode).
- Для общего случая (не только буквы) лучше HashMap.

На собеседованиях часто ожидают решение с подсчётом частот, поэтому рекомендую
использовать HashMap или массив.

---

### Пример

`s = "anagram"`, `t = "nagaram"` → `true`  
`s = "rat"`, `t = "car"` → `false`
