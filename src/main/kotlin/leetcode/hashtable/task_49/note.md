# 49. Group Anagrams

Дан массив строк strs. Сгруппируйте анаграммы. Вы можете вернуть ответ в любом
порядке.

Анаграмма — это слово или фраза, образованная путем перестановки букв другого
слова или фразы с использованием всех исходных букв ровно один раз.

Example 1:

Input: strs = ["eat","tea","tan","ate","nat","bat"]

Output: [["bat"],["nat","tan"],["ate","eat","tea"]]

Объяснение::

- В переменной strs нет строки, которую можно было бы переставить, чтобы
  образовать слово "bat".
- Строки "nat" и "tan" являются анаграммами, поскольку их можно переставлять,
  чтобы образовать одну единственную.
- Строки "ate", "eat" и "tea" являются анаграммами, поскольку их можно
  переставлять, чтобы образовать одну единственную.

Example 2:

Input: strs = [""]

Output: [[""]]

Example 3:

Input: strs = ["a"]

Output: [["a"]]

## Решение

Задача 49. Group Anagrams (Группировка анаграмм) — это отличная задача средней
сложности (Medium). Хотя её часто не относят к «чистым» жадным алгоритмам, она
потрясающе развивает навык работы с хэш-таблицами (HashMap) и эффективной
группировки данных.

## Суть задачи

Тебе дан массив строк strs. Нужно сгруппировать анаграммы вместе. Ответ можно
вернуть в любом порядке.

Анаграмма — это слово, образованное путем перестановки букв другого слова.
Простыми словами: если в двух словах одинаковый набор букв и каждая буква
встречается одинаковое количество раз, то это анаграммы (например, eat, tea и
ate).


## Главный секрет решения

Чтобы сгруппировать анаграммы вместе, нам нужен общий ключ для каждой группы.
Как понять, что слова eat и tea принадлежат к одной группе?
Если мы отсортируем буквы в каждом слове по алфавиту, то:

* eat превратится в aet
* tea превратится в aet
* ate превратится в aet

Отсортированная строка aet станет идеальным ключом для нашего HashMap. Сама
карта будет устоена так:

* Ключ (String): Отсортированное слово (например, "aet").
* Значение (List): Список всех оригинальных слов, которые в него
  превратились (["eat", "tea", "ate"]).


## Код на Kotlin

В Kotlin эта задача решается невероятно элегантно благодаря богатой стандартной
библиотеке:
```kotlin
class Solution {
    fun groupAnagrams(strs: Array<String>): List<List<String>> {
// Создаем карту: ключ — отсортированная строка, значение — список анаграмм
        val anagramMap = HashMap<String, MutableList<String>>()

        for (str in strs) {
            // 1. Сортируем буквы в текущем слове, чтобы получить единый ключ
            // "tea" -> ['t', 'e', 'a'] -> ['a', 'e', 't'] -> "aet"
            val sortedKey = str.toCharArray().sorted().joinToString("")

            // 2. Если такого ключа еще нет в карте, создаем для него пустой список
            if (!anagramMap.containsKey(sortedKey)) {
                anagramMap[sortedKey] = mutableListOf()
            }

            // 3. Добавляем ОРИГИНАЛЬНОЕ слово в список этой группы
            anagramMap[sortedKey]?.add(str)
        }

        // Возвращаем только значения карты (списки сгруппированных слов)
        return anagramMap.values.toList()
    }

}

```


💡 Kotlin-магия: Код внутри цикла for можно сократить до одной строчки с помощью
метода getOrPut:
anagramMap.getOrPut(sortedKey) { mutableListOf() }.add(str)


## Пошаговый разбор на примере: strs = ["eat", "tea", "tan", "ate", "nat", "bat"]

1. eat: сортируем $\rightarrow$ "aet". Карты нет? Создаем. Кладем: {"
   aet": ["eat"]}
2. tea: сортируем $\rightarrow$ "aet". Ключ есть! Добавляем: {"
   aet": ["eat", "tea"]}
3. tan: сортируем $\rightarrow$ "ant". Создаем новый ключ: {"aet": [...], "
   ant": ["tan"]}
4. ate: сортируем $\rightarrow$ "aet". Ключ есть! Добавляем: {"
   aet": ["eat", "tea", "ate"], ...}
5. nat: сортируем $\rightarrow$ "ant". Ключ есть! Добавляем к "ant": [... "
   ant": ["tan", "nat"]]
6. bat: сортируем -> "abt". Создаем новый ключ: {"abt": ["bat"]}

В конце мы берем anagramMap.values и получаем три аккуратные группы.
------------------------------

## 📊 Сложность алгоритма

* Времени: O(N * K log K), где N — количество слов в массиве, а K —
  максимальная длина одного слова. Нам нужно пройтись по всем N словам, и для
  каждого отсортировать буквы (сортировка занимает K log K).
* Памяти: O(N * K) — память, необходимая для хранения всех строк внутри
  нашей хэш-таблицы.

## ⚡ Продвинутый лайфхак (Сортировка подсчетом)

Если на собеседовании тебя спросят: "А можно ли убрать из сложности $\log K$ (
сортировку)?", ты можешь ответить: Да!
Так как слова состоят только из строчных английских букв (их всего 26), вместо
сортировки слова можно составлять ключ в виде массива-счетчика из 26 чисел, где
индекс — это буква, а значение — сколько раз она встретилась (например, ключ
превратится в строку "1#1#0#0#1..."). Это ускорит алгоритм
до O(N * K) [LicensedMediaService: fetch_images].
