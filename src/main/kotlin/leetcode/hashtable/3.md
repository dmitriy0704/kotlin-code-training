# 3. Longest Substring Without Repeating Characters

## Условие

Дана строка s. Найдите длину самой длинной подстроки без повторяющихся символов.

Example 1:
Input: s = "abcabcbb"
Output: 3
Пояснение: Правильный ответ — «abc», его длина равна 3. Обратите внимание, что
«bca» и «cab» также являются правильными ответами.

Example 2:
Input: s = "bbbbb"
Output: 1
Пояснение: Ответ — «б», длина которого равна 1.

Example 3:
Input: s = "pwwkew"
Output: 3
Пояснение: Ответ — «wke», длиной 3. Обратите внимание, что ответ должен быть
подстрокой, «pwke» — это подпоследовательность, а не подстрока.

## Решение

## Задача 3. Longest Substring Without Repeating Characters (LeetCode)

**Условие:**  
Дана строка `s`. Нужно найти длину **самой длинной подстроки** (не
подпоследовательности!) без повторяющихся символов.

**Примеры:**

- Вход: `"abcabcbb"` → Выход: `3` (подстрока `"abc"`)
- Вход: `"bbbbb"` → Выход: `1` (подстрока `"b"`)
- Вход: `"pwwkew"` → Выход: `3` (подстрока `"wke"`)

---

### Идея решения: скользящее окно (Sliding Window) + HashMap

Будем двигать по строке два указателя: `left` (начало текущей подстроки) и
`right` (конец).  
**Хеш-таблица** будет хранить **последнюю позицию** каждого символа.

**Алгоритм:**

1. Идём по строке указателем `right`.
2. Если символ `s[right]` уже встречался в текущем окне (его индекс ≥ `left`),
   перемещаем `left` на позицию после предыдущего вхождения этого символа.
3. Обновляем в карте позицию текущего символа на `right`.
4. Вычисляем длину текущего окна: `right - left + 1` и обновляем `maxLength`.

Этот подход работает за **O(n)** по времени и **O(min(m, n))** по памяти, где
`m` — размер алфавита.

---

### Код на Kotlin (рекомендуемый вариант)

```kotlin
class Solution {
    fun lengthOfLongestSubstring(s: String): Int {
        var maxLength = 0
        var left = 0
        // Храним символ → его последний индекс
        val lastIndexMap = mutableMapOf<Char, Int>()

        for (right in s.indices) {
            val currentChar = s[right]

            // Если символ уже есть в карте и его индекс >= left,
            // значит он внутри текущего окна → смещаем left
            if (lastIndexMap.containsKey(currentChar) && lastIndexMap[currentChar]!! >= left) {
                left = lastIndexMap[currentChar]!! + 1
            }

            // Обновляем позицию текущего символа
            lastIndexMap[currentChar] = right

            // Обновляем максимальную длину
            maxLength = maxOf(maxLength, right - left + 1)
        }

        return maxLength
    }
}
```

**Как это работает:**

- `lastIndexMap` хранит для каждого символа индекс его **последнего** вхождения.
- Если символ уже был в текущем окне, `left` перескакивает за его предыдущую
  позицию.
- Длина окна = `right - left + 1`.

### Альтернативный вариант: с HashSet (два указателя)

Можно использовать `HashSet` для хранения символов текущего окна:

```kotlin
class Solution {
    fun lengthOfLongestSubstring(s: String): Int {
        var maxLength = 0
        var left = 0
        val windowSet = mutableSetOf<Char>()

        for (right in s.indices) {
            // Если символ уже есть в окне, удаляем символы слева
            while (s[right] in windowSet) {
                windowSet.remove(s[left])
                left++
            }
            windowSet.add(s[right])
            maxLength = maxOf(maxLength, right - left + 1)
        }

        return maxLength
    }
}
```

---

### Сравнение подходов

| Подход                  | Время        | Память       | Особенность                                             |
|-------------------------|--------------|--------------|---------------------------------------------------------|
| HashMap с индексами     | O(n)         | O(min(m, n)) | Более оптимальный, один проход                          |
| HashSet + два указателя | O(2n) = O(n) | O(min(m, n)) | Проще для понимания, но может удалять по одному символу |

---

### Проверка на примерах

```kotlin
fun main() {
    val solution = Solution()
    println(solution.lengthOfLongestSubstring("abcabcbb")) // 3
    println(solution.lengthOfLongestSubstring("bbbbb"))   // 1
    println(solution.lengthOfLongestSubstring("pwwkew"))  // 3
    println(solution.lengthOfLongestSubstring(""))        // 0
    println(solution.lengthOfLongestSubstring("dvdf"))    // 3 ("vdf")
}
```

---

### Почему это хеш-таблица?

Хеш-таблица (`HashMap`) здесь используется для:

- **Быстрой проверки** наличия символа в текущем окне — O(1).
- **Хранения позиции** символа, чтобы быстро перемещать `left` при повторе.

Именно использование `HashMap` превращает наивный O(n²) алгоритм в эффективный
O(n).
