# 49. Group Anagrams

## Условие

Дан массив строк strs. Сгруппируйте анаграммы. Вы можете вернуть ответ в любом
порядке.

Анаграмма — это слово или фраза, образованная путем перестановки букв другого
слова или фразы с использованием всех исходных букв ровно один раз.

Example 1:

Input: strs = ["eat","tea","tan","ate","nat","bat"]

Output: [["bat"],["nat","tan"],["ate","eat","tea"]]

Объяснение::

- В переменной strs нет строки, которую можно было бы переставить, чтобы
  образовать слово "bat".
- Строки "nat" и "tan" являются анаграммами, поскольку их можно переставлять,
  чтобы образовать одну единственную.
- Строки "ate", "eat" и "tea" являются анаграммами, поскольку их можно
  переставлять, чтобы образовать одну единственную.

Example 2:

Input: strs = [""]

Output: [[""]]

Example 3:

Input: strs = ["a"]

Output: [["a"]]

## Решение

## Задача 49. Group Anagrams (LeetCode)

**Условие:**  
Дан массив строк `strs`. Нужно сгруппировать анаграммы вместе. Вернуть список
списков строк, где каждая группа содержит анаграммы друг друга.

**Пример:**  
Вход: `["eat", "tea", "tan", "ate", "nat", "bat"]`  
Выход: `[["eat","tea","ate"], ["tan","nat"], ["bat"]]` (порядок групп и
элементов внутри не важен).

---

### Идея решения

Анаграммы имеют одинаковые **отсортированные символы**. Например, "eat" → "
aet", "tea" → "aet". Значит, можно использовать **отсортированную версию строки
как ключ** в хеш-таблице, а в качестве значения хранить список всех исходных
строк, дающих этот ключ.

**Альтернативный подход:** вместо сортировки можно использовать **подсчёт частот
символов** (массив из 26 для латинских букв) и преобразовывать его в
строку-ключ, например `"1#0#2#..."`. Это гарантирует O(n * k) вместо O(n * k log
k) при сортировке, где `k` — максимальная длина строки.

В Kotlin есть встроенная функция `groupBy`, которая идеально подходит для этой
задачи.

---

### Решение 1. Сортировка (просто и понятно)

```kotlin
fun groupAnagrams(strs: Array<String>): List<List<String>> {
    val map = mutableMapOf<String, MutableList<String>>()
    for (str in strs) {
        val key = str.toCharArray().sorted().joinToString("")
        // Получаем список для ключа, если его нет – создаём новый
        map.getOrPut(key) { mutableListOf() }.add(str)
    }
    return map.values.toList()
}
```

**Как это работает:**

- Для каждой строки сортируем её символы, получаем строку-ключ.
- Кладём оригинальную строку в список, соответствующий этому ключу.
- В конце возвращаем все списки значений.

**Сложность:**

- Время: O(n * k log k), где `n` – количество строк, `k` – максимальная длина
  строки (из-за сортировки).
- Память: O(n * k) для хранения всех строк и ключей.

---

### Решение 2. Подсчёт частот (оптимальнее)

Для строк только из строчных латинских букв (по условию задачи так и есть).
Можно создать массив из 26 счётчиков и преобразовать его в строку-ключ.
Например, "eat" даст `"1#0#0#...#1#0#..."` (но можно просто склеить числа через
`#`, чтобы избежать коллизий).

```kotlin
fun groupAnagrams(strs: Array<String>): List<List<String>> {
    val map = mutableMapOf<String, MutableList<String>>()
    for (str in strs) {
        val counts = IntArray(26)
        for (ch in str) {
            counts[ch - 'a']++
        }
        // Строим ключ: например, "1#0#0#...".
        // Важно использовать разделитель, чтобы "1" и "01" не путались.
        val key = counts.joinToString("#")
        map.getOrPut(key) { mutableListOf() }.add(str)
    }
    return map.values.toList()
}
```

**Сложность:**

- Время: O(n * k) – без сортировки.
- Память: O(n * k) – хранение данных.

---

### Решение 3. С использованием `groupBy` (функциональный стиль)

Kotlin предоставляет функцию `groupBy`, которая группирует элементы по ключу,
возвращаемому функцией-селектором.

```kotlin
fun groupAnagrams(strs: Array<String>): List<List<String>> {
    return strs.groupBy {
        it.toCharArray().sorted().joinToString("")
    }.values.toList()
}
```

Это однострочное решение, которое делает всё то же самое, что и первый вариант с
`mutableMapOf`, но более лаконично. Работает быстро, код читабелен.

---

### Какой вариант выбрать?

- Для собеседований чаще всего ожидают решение с сортировкой (оно простое и
  понятное).
- Если нужно показать глубокое понимание и оптимизацию, можно использовать
  подсчёт частот.
- В реальном коде на Kotlin я бы использовал `groupBy` – он короткий и
  выразительный.

Все решения проходят на LeetCode.

---

### Тест на примере

```kotlin
fun main() {
    val strs = arrayOf("eat", "tea", "tan", "ate", "nat", "bat")
    val result = groupAnagrams(strs)
    println(result) // [["eat","tea","ate"], ["tan","nat"], ["bat"]]
}
```
