# 1. Two Sum

## Условие

Дан массив целых чисел nums и целое число target. Необходимо вернуть индексы
этих двух чисел, сумма которых равна target.

Можно предположить, что для каждого входного параметра существует ровно одно
решение, и нельзя использовать один и тот же элемент дважды.

Вы можете вернуть ответ в любом порядке.

Example 1:

Input: nums = [2,7,11,15], target = 9
Output: [0,1]
Explanation: Because nums[0] + nums[1] == 9, we return [0, 1].

## Решение

Задача 1. Two Sum — это самая первая и одна из самых популярных задач на
LeetCode. Она идеально подходит для того, чтобы научиться использовать
Хэш-таблицы (HashMap) для ускорения кода.

## Суть задачи

Тебе даны:

1. Массив целых чисел nums.
2. Целевое число target.

Нужно найти индексы двух чисел в массиве, которые в сумме дают target. Каждый
входной массив гарантированно имеет ровно одно решение, и один и тот же элемент
нельзя использовать дважды.

## Эволюция решения: от медленного к быстрому

## Подход 1: Брутфорс (Перебор всеми циклами)

Мы можем запустить два цикла for и проверить каждую пару чисел.

* Минус: Это очень медленно ($O(N^2)$ времени). Если в массиве будет 100 000
  чисел, код будет работать слишком долго.

## Подход 2: Скользящее окно или Два указателя?

Сортировать массив и сводить указатели к центру здесь нельзя, потому что
сортировка перемешает элементы, а нам нужно вернуть их оригинальные индексы.

## Подход 3: Однопроходный HashMap (Оптимально за O(N))

Мы можем решить задачу за один проход по массиву, если будем использовать
«память» в виде HashMap.
Представь математику: если текущее число это x, то число, которое мы ищем для
пары, равно y = target - x.
Вместо того чтобы искать этот y во всём оставшемся массиве, мы просто
заглядываем в наш черновик (HashMap), куда уже записывали все встреченные ранее
числа и их индексы.


## Код на Kotlin

Вот самое быстрое и лаконичное решение:

```kotlin
class Solution {
    fun twoSum(nums: IntArray, target: Int): IntArray {

      // Input: nums = [2,7,11,15], target = 9

      // Ключ: само число, Значение: его индекс в массиве
        val map = HashMap<Int, Int>()

        for (i in nums.indices) {
            val current = nums[i]

            // Число, которого нам не хватает до target
            val complement = target - current

            // Проверяем, видели ли мы уже нужную пару ранее
            if (map.containsKey(complement)) {
                // Если видели, возвращаем индекс старого числа и индекс текущего
                return intArrayOf(map[complement]!!, i)
            }

            // Если не видели, записываем текущее число и его индекс в карту
            map[current] = i
        }

        // По условию решение всегда есть, но Kotlin требует возвращаемое значение в конце
        throw IllegalArgumentException("Решение не найдено")
    }

}

```


### Пошаговый разбор на примере: nums = [2, 7, 11, 15], target = 9

1. Итерация 1 (i = 0):

   * current = 2.
       * Нам нужно: complement = 9 - 2 = 7.
       * Смотрим в карту: она пустая. Числа 7 там нет.
       * Добавляем текущее число в карту: map[2] = 0. Теперь map = {2 -> 0}.

2. Итерация 2 (i = 1):

   * current = 7.
       * Нам нужно: complement = 9 - 7 = 2.
       * Смотрим в карту: содержит ли она 2? Да! У неё сохранен индекс 0.
       * Условие if сработало. Мы мгновенно возвращаем массив индексов: [0, 1].


## Сложность

* Времени: O(N) — мы проходим по массиву ровно один раз. Поиск элемента в
  HashMap занимает O(1) времени.
* Памяти: O(N) — в худшем случае нам придется сохранить в HashMap почти все
  элементы массива.
