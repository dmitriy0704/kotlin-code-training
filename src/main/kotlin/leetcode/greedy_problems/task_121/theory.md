# Жадный алгоритм

Жадный алгоритм (Greedy Algorithm) — это метод решения задач, который на каждом
шагу делает локально оптимальный выбор в надежде, что в итоге получится
глобально оптимальное решение.
Простыми словами: алгоритм выбирает лучший (самый «выгодный») вариант прямо
сейчас, не заглядывая в будущее и не перебирая другие ветки развития
событий.
В Kotlin этот подход не зависит от самого языка, но лаконичные инструменты
Kotlin (такие как sortedByDescending, sumOf, функции коллекций) позволяют писать
такие алгоритмы очень чисто и компактно.

## Главный принцип жадного алгоритма

1. Жадно схватить лучшее: на каждом этапе берется самый крупный, самый дешевый
   или самый короткий элемент (в зависимости от задачи).
2. Никогда не возвращаться назад: в отличие от DFS (бэктрекинга), жадный
   алгоритм никогда не отменяет свои прошлые шаги. Сделал выбор — пошел дальше.


## Классический пример: Размен монет

Вам нужно выдать покупателю сдачу в 18 рублей минимальным количеством монет.
Доступны монеты номиналом: 10, 5, 2 и 1 рубль.
«Жадная» логика: каждый раз брать самую большую монету, которая помещается в
оставшуюся сумму.

## Реализация на Kotlin:

```kotlin

fun minCoins(coins: IntArray, target: Int): List<Int> {
// 1. Сортируем монеты по убыванию (чтобы "жадно" брать самые крупные)
    val sortedCoins = coins.sortedDescending()
    val result = mutableListOf<Int>()
    var remaining = target

    // 2. Идем по монетам и берем их по максимуму
    for (coin in sortedCoins) {
        while (remaining >= coin) {
            remaining -= coin
            result.add(coin) // Забираем монету
        }
    }
    return result

}
fun main() {
    val availableCoins = intArrayOf(1, 2, 5, 10)
    val change = minCoins(availableCoins, 18)
    println(change) // Выведет: [10, 5, 2, 1] (всего 4 монеты)
}

```


## В чем подвох жадных алгоритмов?

Жадный алгоритм работает очень быстро (обычно за время сортировки O(N log N)
или просто за линейное время O(N)), но он не всегда дает правильный ответ.
Представьте, что из прошлого примера убрали монету 5, но добавили монету 7.
Номиналы: 10, 7, 1. Нам нужно набрать 14 рублей.

* Жадный алгоритм возьмет 10, останется 4. Затем возьмет четыре монеты по 1.
  Итог: [10, 1, 1, 1, 1] (5 монет).
* Идеальное решение: взять две монеты по 7. Итог: [7, 7] (2 монеты).

Жадный алгоритм с треском провалился, потому что выбрал 10 на первом шаге и ослеп к более выгодной комбинации семерок. Задачи, где жадный алгоритм не работает, обычно решаются через Динамическое программирование (DP).

## Шпаргалка для LeetCode: Когда применять?

Выбирайте жадный подход, если:

1. В задаче просят что-то минимизировать или максимизировать (например,
   минимальное число платформ для поездов, максимальная прибыль от акций).
2. Очевиден критерий выбора (сортировка по времени окончания, по стоимости за
   грамм, по размеру).
