# 121. Best Time to Buy and Sell Stock

## Условие

Вам дан массив prices, где prices[i] — цена данной акции на i-й день.

Вы хотите максимизировать свою прибыль, выбрав один день для покупки одной акции
и другой день в будущем для ее продажи.

Верните максимальную прибыль, которую вы можете получить от этой сделки. Если вы
не можете получить никакой прибыли, верните 0.

Example 1:

Input: prices = [7,1,5,3,6,4]
Output: 5
Результат: 5
Пояснение: Покупка на 2-й день (цена = 1) и продажа на 5-й день (цена = 6),
прибыль = 6-1 = 5.
Обратите внимание, что покупка на второй день и продажа на первый день не
допускаются, поскольку вы должны сначала купить, а затем продать.

Example 2:

Input: prices = [7,6,4,3,1]
Output: 0
Пояснение: В этом случае никаких транзакций не совершается, и максимальная
прибыль равна 0.

## Решение

Задача 121. Best Time to Buy and Sell Stock (Лучшее время для покупки и продажи
акций) — это идеальный пример жадного алгоритма (Greedy) и подхода одного
прохода.

## Суть задачи

Тебе дан массив prices, где prices[i] — это цена акции в i-й день.
Ты можешь купить акцию только в один день и продать её в другой, более поздний
день. Нужно найти максимальную прибыль, которую ты можешь получить. Если прибыль
получить невозможно, верни 0.
Пример: prices = [7, 1, 5, 3, 6, 4]

* Если купить во 2-й день (цена = 1) и продать в 5-й день (цена = 6), прибыль
  будет 6 - 1 = 5. Это максимум.
* Купить за 1 и продать за 7 нельзя, так как 7 идет до 1 (нельзя продать в
  прошлом).

## Жадная стратегия: Покупай на самом дне, фиксируй прибыль на пике

Вместо того чтобы перебирать все возможные пары дней (что заняло бы O(N^2)
времени), мы будем действовать «жадно» за один проход O(N):

1. Мы идем по массиву слева направо и ищем самую низкую цену для покупки,
   которую мы встретили к текущему моменту (minPrice).
2. В этот же самый момент мы «жадно» проверяем: если бы мы купили акцию по этой
   минимальной цене minPrice, а продали прямо сейчас по текущей цене, какой была
   бы прибыль?
3. Если эта гипотетическая прибыль больше, чем всё, что мы видели раньше, мы
   обновляем наш рекорд (maxProfit).

## Код на Kotlin

```kotlin

//import kotlin.math.maximport kotlin.math.min
class Solution {
    fun maxProfit(prices: IntArray): Int {
        // Если дней для торговли нет или всего один, прибыль получить нельзя
        if (prices.size < 2) return 0

        var minPrice =
            Int.MAX_VALUE // Самая низкая цена покупки (инициализируем бесконечностью)
        var maxProfit = 0            // Максимальная зафиксированная прибыль

        for (price in prices) {
            // Жадно обновляем минимальную цену, если нашли вариант дешевле
            minPrice = min(minPrice, price)

            // Считаем прибыль, если бы продали акцию прямо сегодня
            val currentProfit = price - minPrice

            // Жадно обновляем максимальную прибыль
            maxProfit = max(maxProfit, currentProfit)
        }

        return maxProfit
    }

}

```

## Пошаговый разбор на примере: prices = [7, 1, 5, 3, 6, 4]

* День 1 (цена 7):
    * minPrice становится 7.
    * Прибыль сегодня: 7 - 7 = 0. maxProfit = 0.
* День 2 (цена 1):
    * Нашли цену ниже! minPrice падает до 1.
    * Прибыль сегодня: 1 - 1 = 0. maxProfit = 0.
* День 3 (цена 5):
    * minPrice остается 1 (так как 1 < 5).
    * Проверяем продажу: 5 - 1 = 4. Это больше старого рекорда! maxProfit
      становится 4.
* День 4 (цена 3):
    * minPrice остается 1.
    * Проверяем продажу: 3 - 1 = 2. Наш рекорд 4 лучше, ничего не меняем.
* День 5 (цена 6):
    * minPrice все еще 1.
    * Проверяем продажу: 6 - 1 = 5. Новый рекорд! maxProfit становится 5.
* День 6 (цена 4):
    * minPrice равен 1.
    * Проверяем продажу: 4 - 1 = 3. Рекорд 5 устоял.

Массив закончился, функция возвращает 5.

## Сложность

* Времени: O(N) — один единственный цикл по массиву.
* Памяти: O(1) — выделили память всего под две переменные.

## 1. var minPrice = Int.MAX_VALUE

Int.MAX_VALUE — это встроенная константа в Kotlin (и Java), которая хранит
максимально возможное целое число (а именно 2 147 483 647).
Зачем мы инициализируем цену покупки таким огромным числом?
Нам нужно найти самую маленькую цену в массиве. Для этого в цикле мы пишем:

minPrice = min(minPrice, price).
Чтобы эта проверка правильно сработала на самом первом элементе массива,
стартовое значение minPrice должно быть гарантированно больше любой цены из
теста.

* Если бы мы поставили var minPrice = 0, то при первой цене акции, например, 7,
  функция min(0, 7) выбрала бы 0. Алгоритм решил бы, что акция стоит 0 рублей, и
  мы никогда бы не обновили цену на реальную.
* А так как Int.MAX_VALUE — это «бесконечность» для компьютера, любое реальное
  число из массива (будь то 7, 100 или 1) окажется меньше него, и алгоритм на
  первом же шаге корректно перезапишет minPrice первой реальной ценой акции.

## 2. var maxProfit = 0

Здесь мы создаем переменную для хранения максимальной прибыли, которую сможем
заработать. Мы ставим её равной 0, потому что:

1. В самом начале мы еще ничего не купили и не продали, наша текущая прибыль
   равна нулю.
2. По условию задачи, если мы вообще не можем получить выгоду (например, цены
   акций каждый день только падали: [7, 6, 4, 3, 1]), мы должны вернуть 0.

Внутри цикла мы будем сравнивать каждую новую потенциальную прибыль с этой
переменной: maxProfit = max(maxProfit, currentProfit). Если мы найдем сделку,
которая приносит, например, 5 рублей прибыли, maxProfit обновится с 0 на 5. Если
все сделки будут уходить в минус, maxProfit так и останется нулем, что мы в
конце и вернем.

Давай пошагово разберем, как меняются эти переменные внутри цикла на примере
массива цен prices = [7, 1, 5, 3, 6, 4].
Вот как выглядит наша математическая лаборатория до старта цикла:

* minPrice = 2147483647 (то самое Int.MAX_VALUE)
* maxProfit = 0
