# 9. Palindrome Number

## Условие

Если задано целое число x, верните true, если x является палиндромом, и false в
противном случае.

Example 1:

Input: x = 121
Output: true
Пояснение: число 121 читается как 121 слева направо и справа налево.

Example 2:

Input: x = -121
Output: false
Пояснение: Слева направо читается -121. Справа налево получается 121-.
Следовательно, это не палиндром.

Example 3:

Input: x = 10
Output: false
Пояснение: Цифра 01 читается справа налево. Следовательно, это не палиндром.

## Решение

Задача 9. Palindrome Number (Число-палиндром) — это еще одна классическая
задача, которая часто встречается на собеседованиях для начинающих
разработчиков.

## Суть задачи

Тебе дано целое число x. Нужно вернуть true, если число является палиндромом, и
false в противном случае.

Число-палиндром читается одинаково как слева направо, так и справа налево.
Например, 121 — палиндром, а 123 — нет.

Важное ограничение: Все отрицательные числа (например, -121) автоматически не
являются палиндромами, потому что слева направо они читаются как -121, а справа
налево — как 121- (знак минус всё портит).

## Два подхода к решению## Подход 1: Перевод в строку (Простой способ)

Самое очевидное решение — превратить число в строку, а затем проверить её с
помощью метода двух указателей (или встроенного метода reversed()).

```kotlin
class Solution {
    fun isPalindrome(x: Int): Boolean {
        val s = x.toString()
        return s == s.reversed()
    }
}

```

* Минус: Этот способ создает новый объект строки в памяти. На собеседованиях
  интервьюеры часто добавляют ограничение: «Решите задачу без перевода числа в
  строку».

## Подход 2: Математический разворот числа (Оптимально)

Мы можем развернуть число математически, используя операции деления со значением
остатка.

Чтобы получить последнюю цифру числа, мы берем остаток от деления на 10 (x %
10). Чтобы «нарастить» разворачиваемое число, мы умножаем его на 10 и добавляем
эту цифру.

Более того, нам не обязательно разворачивать число целиком. Достаточно
развернуть только его заднюю половину и сравнить её с передней! Как только
развернутая часть станет больше или равна оставшейся передней части, мы
останавливаемся.

## Оптимальный код на Kotlin (Без строк)

Вот чистое математическое решение, которое работает за $O(\log N)$ времени
и $O(1)$ памяти:

```kotlin

class Solution {
    fun isPalindrome(x: Int): Boolean {
// Отрицательные числа не палиндромы.
// Также числа, оканчивающиеся на 0, не могут быть палиндромами (кроме самого 0) 
// так как никакое число не начинается с нуля.
        if (x < 0 || (x % 10 == 0 && x != 0)) {
            return false
        }

        var number = x
        var revertedNumber = 0

        // Разворачиваем только вторую половину числа
        while (number > revertedNumber) {
            val lastDigit = number % 10
            revertedNumber = revertedNumber * 10 + lastDigit
            number /= 10
        }

        // Если длина числа была четной (например, 1221), то в конце number == revertedNumber (12 == 12).
        // Если длина была нечетной (например, 12321), то в конце revertedNumber будет 123, а number — 12.
        // Центральная цифра (3) нам не важна, поэтому мы можем просто отбросить её, разделив revertedNumber на 10.
        return number == revertedNumber || number == revertedNumber / 10
    }

}

```

## Пошаговый разбор на примере: x = 1221

1. Старт: number = 1221, revertedNumber = 0.
2. Итерация 1:

    * Условие 1221 > 0 верно.
    * lastDigit = 1221 % 10 = 1.
    * revertedNumber = 0 * 10 + 1 = 1.
    * number = 1221 / 10 = 122.

3. Итерация 2:

    * Условие 122 > 1 верно.
    * lastDigit = 122 % 10 = 2.
    * revertedNumber = 1 * 10 + 2 = 12.
    * number = 122 / 10 = 12.

4. Проверка условия цикла:

* number > revertedNumber $\rightarrow$ 12 > 12. Это ложь. Цикл завершается.

Финал: Проверяем number == revertedNumber ($12 == 12$). Это истина. Функция
возвращает true.

## Сложность

* Времени: $O(\log_{10} N)$ — на каждом шаге цикла мы делим число на 10, поэтому
  количество операций пропорционально количеству цифр в числе.
* Памяти: $O(1)$ — мы используем только две переменные типа Int.
