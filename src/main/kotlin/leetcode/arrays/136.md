# 136. Single Number

## Условие

Дан непустой массив целых чисел nums, в котором каждый элемент встречается
дважды, кроме одного. Найдите этот единственный элемент.

Необходимо реализовать решение с линейной временной сложностью и использовать
только постоянное дополнительное пространство.

Example 1:
Input: nums = [2,2,1]
Output: 1

Example 2:
Input: nums = [4,1,2,1,2]
Output: 4

Example 3:
Input: nums = [1]
Output: 1

Constraints:

1 <= nums.length <= 3 * 10^4
-3 * 104 <= nums[i] <= 3 * 10^4

Каждый элемент массива встречается дважды, за исключением одного элемента,
который встречается только один раз.

## Решение

Отличная задача! `136. Single Number` — классика. Да, её можно решить через
`HashMap`, подсчитав частоты, но есть и более элегантный способ через XOR. Я
помогу вам разобраться с вашим кодом и покажу правильные варианты.

---

## Что не так в вашем коде?

Разберём ваш код построчно:

```kotlin
fun singleNumber(nums: IntArray): Int {
    val map = mutableMapOf<Int, Int>()
    var res = 0
    var count = 0
    for (num in nums) {
        map[num] =
            count           // 1) вы присваиваете текущий count (изначально 0)
        if (map.containsKey(num)) { // 2) здесь num уже только что добавлен, так что условие всегда true
            count++                // 3) увеличиваете count на 1
        }
        println("$num, $count")
        res =
            map.minBy { it.value }!!.key  // 4) после каждого шага ищете минимальное значение
    }
    return res
}
```

Проблемы:

- Для каждого `num` вы сначала кладёте в карту значение `count` (которое сначала
  0), а потом увеличиваете `count`. Но это не подсчёт частот, потому что `count`
  общий для всех элементов, а не для каждого ключа отдельно.
- Условие `if (map.containsKey(num))` всегда `true`, потому что вы только что
  добавили этот ключ.
- `map.minBy { it.value }` каждый раз ищет ключ с наименьшим значением — это
  дорого (O(n) на каждой итерации) и неправильно, потому что частоты неверны.
- В итоге вы получите неверный результат.

---

## Правильный способ с HashMap

Чтобы подсчитать частоты, для каждого числа нужно увеличивать счётчик, связанный
именно с этим числом. Используйте `getOrDefault`:

```kotlin
fun singleNumber(nums: IntArray): Int {
    val map = mutableMapOf<Int, Int>()
    for (num in nums) {
        // Увеличиваем счётчик для num на 1
        map[num] = map.getOrDefault(num, 0) + 1
    }
    // Ищем ключ, у которого значение = 1
    for ((key, value) in map) {
        if (value == 1) return key
    }
    // По условию такое число всегда есть
    return -1
}
```

Или более функционально:

```kotlin
fun singleNumber(nums: IntArray): Int {
    val freq = nums.groupingBy { it }.eachCount()  // Map<Int, Int>
    return freq.entries.find { it.value == 1 }!!.key
}
```

**Сложность:** O(n) времени, O(n) памяти.

## Почему лучше использовать XOR

В этой задаче есть **идеальное решение** со сложностью O(n) по времени и O(1) по
памяти. Оно основано на свойствах XOR (исключающее ИЛИ):

- `a xor a = 0`
- `a xor 0 = a`
- XOR ассоциативен и коммутативен.

Если применить XOR ко всем элементам массива, то все числа, встречающиеся
дважды, взаимно уничтожатся, и останется только уникальное.

```kotlin
fun singleNumber(nums: IntArray): Int {
    var result = 0
    for (num in nums) {
        result = result xor num
    }
    return result
}
```

Или в функциональном стиле:

```kotlin
fun singleNumber(nums: IntArray): Int = nums.reduce { acc, i -> acc xor i }
```

**Пример:** `[4, 1, 2, 1, 2]`  
`4 xor 1 xor 2 xor 1 xor 2 = (1 xor 1) xor (2 xor 2) xor 4 = 0 xor 0 xor 4 = 4`

Это решение — самое быстрое и экономное по памяти, и оно часто ожидается на
собеседованиях.
