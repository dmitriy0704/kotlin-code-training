# 26. Remove Duplicates from Sorted Array

## Условие

Дан целочисленный массив nums, отсортированный в порядке неубывания. Необходимо
удалить дубликаты на месте таким образом, чтобы каждый уникальный элемент
встречался только один раз. Относительный порядок элементов должен оставаться
неизменным.

Пусть количество уникальных элементов в массиве nums равно k. После удаления
дубликатов верните количество уникальных элементов k.

Первые k элементов массива nums должны содержать уникальные числа в
отсортированном порядке. Остальные элементы после индекса k - 1 можно
игнорировать.

Пользовательский судья:

Судья проверит ваше решение с помощью следующего кода:

```code

int[] expectedNums = [...]; // The expected answer with correct length

assert k == expectedNums.length;
for (int i = 0; i < k; i++) {
    assert nums[i] == expectedNums[i];
}

```

Если все утверждения пройдут успешно, ваше решение будет принято.

Example 1:

Input: nums = [1,1,2]
Output: 2, nums = [1,2,_]
Пояснение: Ваша функция должна возвращать k = 2, при этом первые два элемента
массива nums должны быть равны 1 и 2 соответственно.

Неважно, что вы оставите после возвращаемого значения k (поэтому это
подчеркивания).

Constraints:

1 <= nums.length <= 3 * 104
-100 <= nums[i] <= 100
nums is sorted in non-decreasing order.

## Решение

## Решение задачи 26. Remove Duplicates from Sorted Array на Kotlin

**Задача:**  
Дан отсортированный массив целых чисел `nums`. Нужно удалить дубликаты **на
месте** (in-place) так, чтобы каждый элемент встречался не более одного раза, и
вернуть новую длину массива. Порядок элементов должен сохраняться. После
изменения первые `k` элементов должны содержать уникальные значения, а что
находится за пределами `k` — не важно.

**Ограничения:**

- Массив отсортирован по неубыванию.
- Нельзя использовать дополнительный массив, нужно изменять исходный.

---

### Идея решения – два указателя (Two Pointers)

Используем два индекса:

- `i` — медленный указатель, который отслеживает позицию последнего *
  *уникального** элемента.
- `j` — быстрый указатель, который перебирает все элементы массива.

Алгоритм:

1. Если массив пуст, сразу возвращаем `0`.
2. Устанавливаем `i = 0` (первый элемент уже уникален, считаем его).
3. Запускаем цикл по `j` от `1` до `nums.size - 1`:
    - Если `nums[j] != nums[i]` (нашли новый уникальный элемент), то:
        - Увеличиваем `i` на 1.
        - Копируем `nums[j]` в `nums[i]`.
4. После завершения цикла `i + 1` — это количество уникальных элементов (новая
   длина). Возвращаем `i + 1`.

---

### Код на Kotlin

```kotlin
class Solution {
    fun removeDuplicates(nums: IntArray): Int {
        if (nums.isEmpty()) return 0

        var i = 0 // медленный указатель на последний уникальный элемент
        for (j in 1 until nums.size) {
            if (nums[j] != nums[i]) {
                i++
                nums[i] = nums[j]
            }
        }
        return i + 1
    }
}
```

**Пояснение:**

- `i` изначально указывает на `nums[0]`, который точно уникален.
- Когда встречаем новый элемент (отличный от того, на который указывает `i`), мы
  сдвигаем `i` и записываем этот элемент на новую позицию.
- В итоге первые `i+1` элементов содержат все уникальные значения в правильном
  порядке.
- Возвращаемое значение `i+1` — новая длина.

---

### Пример работы

```
nums = [1, 1, 2, 3, 3]
i = 0
j = 1: nums[1] == nums[0] -> пропускаем
j = 2: nums[2] = 2 != nums[0] -> i = 1, nums[1] = 2
j = 3: nums[3] = 3 != nums[1] -> i = 2, nums[2] = 3
j = 4: nums[4] == nums[2] -> пропускаем
Результат: nums = [1, 2, 3, 3, 3] (первые 3 элемента уникальны), возвращаем 3.
```

---

### Сложность

- **Время:** O(n) — один проход по массиву.
- **Память:** O(1) — только две переменные, никаких дополнительных массивов.

- В Kotlin массив передаётся по ссылке, поэтому изменения внутри функции

- В LeetCode тестировщик проверяет только первые `k` элементов после вызова
  функции, поэтому возвращаемая длина важна.

Отличный вопрос! Вы имеете в виду условие: после работы функции массив должен
быть **модифицирован на месте** так, чтобы **первые `k` элементов** содержали
уникальные значения в исходном порядке, а что находится за пределами `k` — не

### Почему первые `k` элементов будут корректны?

- В нашем алгоритме медленный указатель `i` всегда указывает на последний **уже
  записанный уникальный** элемент.
- Когда мы находим новый элемент `nums[j] != nums[i]`, мы увеличиваем `i` и
  копируем `nums[j]` на позицию `i`.  
  Таким образом, все элементы с индексами `0..i` — это строго возрастающая
  последовательность уникальных значений (поскольку исходный массив
  отсортирован, и мы пропускаем повторы).
- После завершения цикла `i` равен индексу последнего уникального элемента, а
  количество уникальных элементов = `i + 1 = k`.  
  Это значение мы и возвращаем.

### Что насчёт «не больше k»?

В условии задачи сказано: «Возвращаемая длина `k` должна быть **минимальной** (
т.е. количеством уникальных элементов)». Мы не ограничиваем `k` сверху — оно
ровно столько, сколько уникальных значений. И мы гарантируем, что **первые `k`**
элементов не содержат дубликатов. Остальные элементы за пределами `k` могут быть
любыми (обычно там остаются старые значения), и это допустимо.

## Разберём ваш конкретный вопрос по шагам

Вы смотрите на пример:

```kotlin
nums = [0, 0, 1, 1, 1, 2, 2, 3, 3, 4]
```

### Состояние до шага j = 5

Мы уже прошли некоторые элементы:

- **Начало:** `i = 0` (первый уникальный элемент — `nums[0] = 0`).
- **j = 1:** `nums[1] = 0`, равно `nums[0]` → пропускаем.
- **j = 2:** `nums[2] = 1`, не равно `0` → делаем `i++` → теперь `i = 1`,
  записываем `nums[1] = 1`.
- **j = 3:** `nums[3] = 1`, равно `nums[1] = 1` → пропускаем.
- **j = 4:** `nums[4] = 1`, равно `nums[1] = 1` → пропускаем.

Теперь мы на **j = 5**, массив выглядит так (после записей):

```
[0, 1, 1, 1, 1, 2, 2, 3, 3, 4]
         ↑
      i = 1 (последний записанный уникальный элемент — 1)
```

### Шаг j = 5

- `nums[j] = nums[5] = 2`
- `nums[i] = nums[1] = 1`
- Проверяем: `2 != 1` → **да, это новый уникальный элемент!**

Что делаем?

1. Увеличиваем `i` на 1: `i` становится **2** (это индекс, куда мы запишем новый
   уникальный элемент).
2. Записываем: `nums[2] = nums[5] = 2`.

Теперь массив:

```
[0, 1, 2, 1, 1, 2, 2, 3, 3, 4]
         ↑
      i = 2 (последний уникальный — 2)
```

### Почему именно i = 2?

- `i` — это **индекс**, а не значение.
- `i` всегда указывает на последний **уже записанный уникальный** элемент.
- Когда мы находим новый уникальный элемент, мы **сначала** увеличиваем `i` (
  сдвигаем указатель на следующую свободную позицию), а **потом** записываем в
  неё новое значение.
- Поэтому на этом шаге `i` стал равен 2, и мы поместили туда число 2.

### Важно

- Мы не сравниваем `nums[j]` с `i` (индексом). Мы сравниваем **значение**
  `nums[j]` со **значением** `nums[i]` (последнего уникального элемента).
- Новое значение кладётся **на позицию** `i` после её увеличения.
