# 14. Longest Common Prefix

# Условие

Напишите функцию для поиска самой длинной общей префиксной строки среди массива
строк.

Если общего префикса нет, вернуть пустую строку "".

Example 1:
Input: strs = ["flower","flow","flight"]
Output: "fl"

Example 2:
Input: strs = ["dog","racecar","car"]
Output: ""
Пояснение: У входных строк нет общего префикса.

Constraints:

1 <= strs.length <= 200
0 <= strs[i].length <= 200
Если строка strs[i] не пуста, она состоит только из строчных английских букв.

# Решение

## Решение задачи 14. Longest Common Prefix на Kotlin

**Задача:**  
Дан массив строк `strs`. Найти самый длинный общий префикс (префикс, который
является началом всех строк). Если общего префикса нет, вернуть пустую строку
`""`.

---

### Подходы

1. **Горизонтальное сканирование** – берём первую строку как префикс, затем
   последовательно сравниваем с каждой следующей строкой, укорачивая префикс до
   тех пор, пока он не станет её началом.
2. **Вертикальное сканирование** – сравниваем символы всех строк на одинаковых
   позициях, пока они совпадают.
3. **Сортировка** – отсортировать массив, тогда общий префикс всех строк будет
   общим префиксом первой и последней строк (так как они максимально
   различаются).
4. **Разделяй и властвуй**, **Trie** – для больших объёмов, но для обычного
   случая достаточно простых.

---

### Рекомендуемое решение – **вертикальное сканирование**

Оно простое, эффективное (O(S), где S – суммарная длина всех строк) и легко
читается.

**Алгоритм:**

- Если массив пуст, сразу возвращаем `""`.
- Берём первую строку как эталон.
- Проходим по индексам символов этой строки (от 0 до длины-1).
- Для каждого индекса `i` проверяем, что у всех строк длина больше `i` и символ
  на позиции `i` совпадает с символом первой строки.
- Если для какой-то строки условие нарушается, прерываем цикл и возвращаем
  подстроку первой строки от 0 до `i` (не включая `i`).
- Если цикл завершился полностью, значит, первая строка целиком является общим
  префиксом – возвращаем её.

---

### Код на Kotlin

```kotlin
class Solution {
    fun longestCommonPrefix(strs: Array<String>): String {
        if (strs.isEmpty()) return ""

        val first = strs[0]
        for (i in first.indices) {
            val ch = first[i]
            for (j in 1 until strs.size) {
                // Если длина строки меньше i+1 или символ не совпадает
                if (i >= strs[j].length || strs[j][i] != ch) {
                    return first.substring(0, i)
                }
            }
        }
        return first
    }
}
```

**Пояснения:**

- `first.indices` – это диапазон индексов символов первой строки.
- Внутренний цикл проходит по всем остальным строкам.
- Если встречаем несовпадение или строка заканчивается раньше, возвращаем
  префикс до текущего индекса.
- Если все строки прошли проверку, значит, первая строка полностью подходит –
  возвращаем её.

### Альтернатива – горизонтальное сканирование (тоже часто используется)

```kotlin
class Solution {
    fun longestCommonPrefix(strs: Array<String>): String {
        if (strs.isEmpty()) return ""
        var prefix = strs[0]
        for (i in 1 until strs.size) {
            while (!strs[i].startsWith(prefix)) {
                prefix = prefix.dropLast(1)
                if (prefix.isEmpty()) return ""
            }
        }
        return prefix
    }
}
```

---

### Сложность

- **Время**: O(S), где S – сумма длин всех строк. В худшем случае (все строки
  одинаковые) мы проверим все символы.
- **Память**: O(1) – мы не создаём дополнительных структур, кроме нескольких
  переменных.

### Что учесть при сдаче на LeetCode

- Обязательно проверять пустой массив – иначе вызов `strs[0]` выбросит
  исключение.
- В Kotlin принято использовать `substring(0, i)` для получения префикса. Можно
  также `first.take(i)`.
- Функция `dropLast(1)` в горизонтальном сканировании создаёт новую строку, но
  это допустимо для небольших данных.
