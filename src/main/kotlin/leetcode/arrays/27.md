# 27. Remove Element

## Условие

Дан массив целых чисел nums и массив целых чисел val. Необходимо удалить все
вхождения val из массива nums на месте. Порядок элементов может быть изменен.
Затем верните количество элементов в массиве nums, которые не равны val.

Рассмотрим количество элементов в массиве nums, которые не равны значению k. Для
того чтобы запрос был принят, необходимо выполнить следующие действия:

- Измените массив nums таким образом, чтобы первые k элементов содержали
  элементы, не равные val. Остальные элементы массива nums, а также размер
  массива nums, не имеют значения.
- Возвращаем k.

Пользовательский судья:

```code

int[] nums = [...]; // Input array
int val = ...; // Значение для удаления
int[] expectedNums = [...]; // Ожидаемый ответ правильной длины.
                            // Отсортировано, нет значений, равных val.

int k = removeElement(nums, val); // Вызывает вашу реализацию

assert k == expectedNums.length;
sort(nums, 0, k); // Отсортируйте первые k элементов числа nums.
for (int i = 0; i < actualLength; i++) {
    assert nums[i] == expectedNums[i];
}

```

Если все утверждения пройдут успешно, ваше решение будет принято.

Example 1:

Input: nums = [3,2,2,3], val = 3
Output: 2, nums = [2,2,_,_]
Пояснение: Ваша функция должна возвращать k = 2, при этом первые два элемента
массива nums равны 2.
Неважно, что вы оставите после возвращаемого значения k (поэтому это
подчеркивания).

Example 2:

Input: nums = [0,1,2,2,3,0,4,2], val = 2
Output: 5, nums = [0,1,4,0,3,_,_,_]
Пояснение: Ваша функция должна возвращать k = 5, причем первые пять элементов
массива nums должны содержать 0, 0, 1, 3 и 4.
Обратите внимание, что пять элементов могут быть возвращены в любом порядке.
Неважно, что вы оставите после возвращаемого значения k (поэтому это
подчеркивания).

Constraints:

0 <= nums.length <= 100
0 <= nums[i] <= 50
0 <= val <= 100

## Решение

## Решение задачи 27. Remove Element на Kotlin

**Задача:**  
Дан массив целых чисел `nums` и целое число `val`. Нужно удалить все элементы,
равные `val`, **на месте** (in-place), и вернуть новую длину массива. Порядок
оставшихся элементов может быть изменён. После изменения первые `k` элементов
должны содержать все элементы, не равные `val`, а что находится за пределами
`k` — не важно.

**Ограничения:**

- Изменяем исходный массив, без создания нового.
- Возвращаем только новую длину.

---

### Идея решения – два указателя

Используем два индекса:

- `i` — медленный указатель, который отслеживает позицию для записи следующего
  подходящего элемента (не равного `val`).
- `j` — быстрый указатель, который перебирает все элементы массива.

Алгоритм:

1. Устанавливаем `i = 0`.
2. Запускаем цикл по `j` от `0` до `nums.size - 1`:

- Если `nums[j] != val`, то:
    - Записываем `nums[j]` в `nums[i]`.
    - Увеличиваем `i` на 1.

3. После завершения цикла `i` равно количеству элементов, не равных `val`.
   Возвращаем `i`.

---

### Код на Kotlin

```kotlin
class Solution {
    fun removeElement(nums: IntArray, `val`: Int): Int {
        var i = 0
        for (j in nums.indices) {
            if (nums[j] != `val`) {
                nums[i] = nums[j]
                i++
            }
        }
        return i
    }
}
```

**Пояснения:**

- `nums.indices` – это диапазон индексов от 0 до последнего.
- Когда встречаем элемент, который **не равен** `val`, мы помещаем его на
  позицию `i` и сдвигаем `i` вперёд.
- Элементы, равные `val`, просто пропускаются (не записываются).
- В конце `i` = количество оставшихся элементов, возвращаем его.

---

### Пример работы

```
nums = [3, 2, 2, 3], val = 3
i = 0
j = 0: nums[0]=3 == val -> пропускаем
j = 1: nums[1]=2 != val -> nums[0]=2, i=1
j = 2: nums[2]=2 != val -> nums[1]=2, i=2
j = 3: nums[3]=3 == val -> пропускаем
Итог: nums = [2, 2, 2, 3] (первые 2 элемента — 2,2), возвращаем 2.
```

```
nums = [0,1,2,2,3,0,4,2], val = 2
i=0
j=0: 0!=2 -> nums[0]=0, i=1
j=1: 1!=2 -> nums[1]=1, i=2
j=2: 2==2 -> пропуск
j=3: 2==2 -> пропуск
j=4: 3!=2 -> nums[2]=3, i=3
j=5: 0!=2 -> nums[3]=0, i=4
j=6: 4!=2 -> nums[4]=4, i=5
j=7: 2==2 -> пропуск
Результат: первые 5 элементов [0,1,3,0,4], возвращаем 5.
```

---

### Сложность

- **Время:** O(n) – один проход по массиву.
- **Память:** O(1) – дополнительная память не используется (кроме пары
  переменных).

---

### Альтернативный подход (для случаев, когда нужно минимизировать перемещения)

Можно использовать два указателя с обоих концов, чтобы перемещать элементы
реже (когда элементов, равных `val`, мало). Но стандартное решение выше
полностью приемлемо.
