# 1. Two Sum

# Условие

Вам дан массив целых чисел nums и целое число target; верните индексы этих двух
чисел, сумма которых равна target.

Можно предположить, что для каждого входного параметра существует ровно одно
решение, и нельзя использовать один и тот же элемент дважды.

Вы можете вернуть ответ в любом порядке.

Example 1:
Input: nums = [2,7,11,15], target = 9
Output: [0,1]
Explanation: Because nums[0] + nums[1] == 9, we return [0, 1].

Example 2:
Input: nums = [3,2,4], target = 6
Output: [1,2]

Example 3:
Input: nums = [3,3], target = 6
Output: [0,1]

Constraints:

2 <= nums.length <= 104
-109 <= nums[i] <= 109
-109 <= target <= 109

Существует только один правильный ответ.

# Решение

## Решение задачи 1. Two Sum на Kotlin

Задача: дан массив целых чисел `nums` и целое число `target`. Нужно вернуть
индексы двух элементов, сумма которых равна `target`. Гарантируется, что решение
существует и единственно, при этом один элемент нельзя использовать дважды.

### Оптимальное решение (через хеш-таблицу)

Используем `MutableMap` для хранения уже просмотренных чисел и их индексов.
Проходим по массиву один раз. Для каждого числа `nums[i]` вычисляем недостающее
слагаемое `complement = target - nums[i]`. Если `complement` уже есть в карте,
значит, мы нашли пару — возвращаем индексы. Если нет — добавляем текущее число и
его индекс в карту.

```kotlin
class Solution {
    fun twoSum(nums: IntArray, target: Int): IntArray {
        val map = mutableMapOf<Int, Int>()
        for (i in nums.indices) {
            val complement = target - nums[i]
            if (map.containsKey(complement)) {
                return intArrayOf(map[complement]!!, i)
            }
            map[nums[i]] = i
        }
        // По условию задачи мы всегда найдём решение, поэтому сюда не попадём
        return intArrayOf()
    }
}
```

**Сложность:**

- Время: O(n) — один проход по массиву.
- Память: O(n) — в худшем случае храним все элементы в карте.

### Альтернативный вариант (brute force) — не рекомендуется

Простой перебор всех пар с двумя вложенными циклами даёт O(n²) по времени, что
для больших массивов слишком медленно.

```kotlin
class Solution {
    fun twoSum(nums: IntArray, target: Int): IntArray {
        for (i in nums.indices) {
            for (j in i + 1 until nums.size) {
                if (nums[i] + nums[j] == target) {
                    return intArrayOf(i, j)
                }
            }
        }
        return intArrayOf()
    }
}
```

Но лучше использовать первый вариант.

### Дополнительные замечания

- В Kotlin оператор `!!` используется для извлечения значения из
  `map[complement]`, так как `get` возвращает nullable-тип. Поскольку мы
  проверяем `containsKey`, значение точно существует.
- Можно избавиться от `!!`, используя `map.getValue(complement)`, но это тоже
  выбрасывает исключение при отсутствии ключа.
- Если хотите более функциональный стиль, можно применить `first` или `find`, но
  это приведёт к дополнительным итерациям.
