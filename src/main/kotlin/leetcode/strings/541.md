# 541. Reverse String II

## Условие

Дана строка s и целое число k.
Необходимо перевернуть первые k символов для каждых 2k символов, считая от
начала строки.

Если осталось меньше k символов, переверните их все. Если осталось меньше 2k, но
больше или равно k символов, то переверните первые k символов, а остальные
оставьте как есть.

Example 1:

Input: s = "abcdefg", k = 2
Output: "bacdfeg"

Example 2:

Input: s = "abcd", k = 2
Output: "bacd"

## Решение

Отлично, давайте решим **задачу 541. Reverse String II**. Твоя мысль про два
указателя абсолютно верна – они нужны **внутри каждого блока**, чтобы
переворачивать его часть. Давай разберёмся, как правильно организовать логику.

---

## 📌 Условие

Дана строка `s` и целое число `k`.  
Нужно перевернуть первые `k` символов в каждой группе из `2k` символов.  
Если в конце остаётся меньше `k` символов – переворачиваем все оставшиеся.  
Если остаётся от `k` до `2k` – переворачиваем только первые `k`, остальное
оставляем как есть.

**Примеры:**

- `s = "abcdefg", k = 2` → `"bacdfeg"`  
  (блок `ab` → `ba`, `cd` → `dc`, остаток `efg` – переворачиваем первые 2:`ef` →
  `fe`, `g` остаётся)
- `s = "abcd", k = 2` → `"bacd"` (блок `ab` → `ba`, `cd` не переворачиваем, т.к.
  это вторая половина)

---

## 💡 Идея решения

Мы будем проходить по строке **блоками длиной `2k`**:

- Внутри каждого блока переворачиваем подстроку с индекса `i` до `i + k - 1` (
  или до конца строки, если остаток меньше `k`).
- Для переворота используем **два указателя** – левый и правый внутри этого
  сегмента.

Таким образом, внешний цикл двигается с шагом `2k`, а внутренний цикл меняет
местами символы внутри первых `k` элементов текущего блока.

---

## 🧠 Алгоритм по шагам

1. Переводим строку в `CharArray`, чтобы менять символы на месте.
2. Переменная `n = s.length`.
3. Цикл `i = 0; i < n; i += 2*k`:
    - `left = i`
    - `right = min(i + k - 1, n - 1)` – последний индекс, который нужно
      перевернуть.
    - Пока `left < right` – меняем местами `arr[left]` и `arr[right]`, сдвигаем
      указатели.
4. Возвращаем новую строку из изменённого массива.

---

## 💻 Код на Kotlin

```kotlin
class Solution {
    fun reverseStr(s: String, k: Int): String {
        val arr = s.toCharArray()
        val n = arr.size

        for (i in 0 until n step (2 * k)) {
            var left = i
            var right = minOf(i + k - 1, n - 1)

            while (left < right) {
                // Обмен без temp через also (но можно и с temp)
                arr[left] = arr[right].also { arr[right] = arr[left] }
                left++
                right--
            }
        }

        return String(arr)
    }
}
```

Если предпочитаешь явный `temp` для читаемости:

```kotlin
val temp = arr[left]
arr[left] = arr[right]
arr[right] = temp
```

## 🧪 Проверка на примерах

```kotlin
fun main() {
    val sol = Solution()
    println(sol.reverseStr("abcdefg", 2)) // "bacdfeg"
    println(sol.reverseStr("abcd", 2))    // "bacd"
    println(sol.reverseStr("a", 2))       // "a"
    println(
        sol.reverseStr(
            "abc",
            3
        )
    )     // "cba" (k=3, вся строка переворачивается)
}
```

## ⏱ Сложность

- **Время:** O(n) – каждый символ участвует в обмене не более одного раза.
- **Память:** O(n) – для `CharArray` (обязательно, так как строки неизменяемы в
  Kotlin).

---

## 📝 Почему твоя идея с двумя указателями работает?

Ты совершенно прав – два указателя внутри каждого блока отвечают за разворот *
*первых `k`** символов.  
Внешний цикл перебирает блоки, а внутренний делает «работу» по обмену.  
Такой подход – классический паттерн «разделяй и властвуй» для строк с
периодическим реверсом.

---

## 💡 Возможные вариации и вопросы на собеседовании

- **Что если `k = 1`?** – ничего не переворачивается, возвращается исходная
  строка.
- **Что если `k` больше длины строки?** – `right = min(k-1, n-1) = n-1`,
  переворачивается вся строка.
- **Можно ли обойтись без `CharArray`?** – можно, но придётся постоянно
  создавать новые строки через `substring`, что менее эффективно. На
  собеседовании лучше показать работу с массивом.

## 🔁 Альтернативный подход (с использованием `substring` и `reversed`)

Хотя это не in-place, но для краткости можно написать так:

```kotlin
fun reverseStr(s: String, k: Int): String = buildString {
    var i = 0
    while (i < s.length) {
        append(s.substring(i, minOf(i + k, s.length)).reversed())
        append(s.substring(minOf(i + k, s.length), minOf(i + 2 * k, s.length)))
        i += 2 * k
    }
}
```

Этот вариант проще для понимания, но использует дополнительную память и выделяет
много подстрок.
