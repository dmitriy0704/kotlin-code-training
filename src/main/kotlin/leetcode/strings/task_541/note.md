# 541. Reverse String II

## Условие

Дана строка s и целое число k.
Необходимо перевернуть первые k символов для каждых 2k символов, считая от
начала строки.

Если осталось меньше k символов, переверните их все. Если осталось меньше 2k, но
больше или равно k символов, то переверните первые k символов, а остальные
оставьте как есть.

Example 1:

Input: s = "abcdefg", k = 2
Output: "bacdfeg"

Example 2:

Input: s = "abcd", k = 2
Output: "bacd"

## Решение

Задача 541. Reverse String II — это отличная задача на работу со строками,
индексами и циклами. Она проверяет твое умение аккуратно управлять шагами цикла
и манипулировать массивом символов.

## Суть задачи

Тебе даны строка s и целое число k. Нужно разворачивать символы строки по
следующему правилу каждые 2k символов:

1. Первые k символов из каждых 2k символов нужно развернуть (reverse).
2. Следующие k символов нужно оставить как есть.

Что делать, если символов в конце осталось мало:

* Если осталось меньше k символов — разворачиваем их все.
* Если осталось от k до 2k символов — разворачиваем первые k, а остальные
  оставляем без изменений.

Простой пример: s = "abcdefg", k = 2.

1. Берем первый блок в 2k = 4 символа: "abcd". Первые два (k=2) разворачиваем,
   вторые два оставляем: "ba" + "cd" = "bacd".
2. Смотрим на остаток: "efg". Тут всего 3 символа. Это меньше 2k, но больше или
   равно k. Значит, разворачиваем первые два ("ef" -> "fe"), а
   последний оставляем: "fe" + "g" = "feg".
3. Итог: "bacdfeg".


## Суть решения: Шаг в 2k и метод двух указателей

Самый эффективный способ решить эту задачу на Kotlin — перевести строку в
изменяемый массив символов (CharArray), а затем двигаться по нему циклом for с
шагом 2 * k.
Внутри каждой итерации мы будем запускать классический разворот (как в 
задаче 344. Reverse String) с помощью двух указателей left и right:

* left всегда стартует с начала текущего блока (индекс i).
* right должен встать на k элементов дальше, то есть на i + k - 1. Но здесь
  нужно быть осторожным: если до конца строки осталось меньше k символов, right
  вылетит за границы массива. Чтобы этого не произошло, мы берем минимум: min(
  i + k - 1, s.length - 1).


## Код на Kotlin

Вот лаконичное и быстрое решение:

```kotlin
// import kotlin.math.min
class Solution {
fun reverseStr(s: String, k: Int): String {
val chars = s.toCharArray()

        // Шагаем по строке большими блоками размером 2 * k
        for (i in 0 until chars.size step 2 * k) {
            var left = i
            // Вычисляем правую границу для разворота (не вылетая за пределы массива)
            var right = min(i + k - 1, chars.size - 1)
            
            // Разворачиваем кусочек внутри массива chars с помощью двух указателей
            while (left < right) {
                val temp = chars[left]
                chars[left] = chars[right]
                chars[right] = temp
                left++
                right--
            }
        }
        
        // Превращаем массив символов обратно в строку
        return String(chars)
    }

}

```



## Пошаговый разбор на примере: s = "abcdefg", k = 2

Длина массива символов chars равна 7. Цикл будет шагать с шагом 2 * k = 4.

1. Итерация 1 (i = 0):

* left = 0 (указывает на 'a').
    * right = min(0 + 2 - 1, 6) = 1 (указывает на 'b').
    * Цикл while меняет местами 'a' и 'b'.
    * Массив становится: ['b', 'a', 'c', 'd', 'e', 'f', 'g'].

2. Итерация 2 (i = 4):

* left = 4 (указывает на 'e').
    * right = min(4 + 2 - 1, 6) = min(5, 6) = 5 (указывает на 'f').
    * Цикл while меняет местами 'e' и 'f'.
    * Массив становится: ['b', 'a', 'c', 'd', 'f', 'e', 'g'].

3. Следующий шаг (i = 8):

* Условие цикла i < chars.size больше не выполняется (8 < 7 — ложь). Цикл
  завершается.

Функция преобразует массив в строку и возвращает "bacdfeg".

## 📊 Сложность алгоритма

* Времени: O(N) — мы проходим по всей строке один раз. Каждый символ либо
  участвует в развороте (одна операция обмена), либо просто пропускается.
* Памяти: O(N) — нам пришлось создать массив символов CharArray размера N,
  чтобы изменять элементы на месте, так как строки (String) в Kotlin и Java
  неизменяемы (immutable).
