# 917. Reverse Only Letters

## Условие

Дана строка s. Необходимо перевернуть её в соответствии со следующими правилами:

- Все символы, кроме английских букв, остаются на своих местах.
- Все английские буквы (строчные и заглавные) должны быть перевернуты. Верните
  строку s после переворачивания.

Верните s после его инвертирования.

Example 1:

Input: s = "ab-cd"
Output: "dc-ba"

Example 2:

Input: s = "a-bC-dEf-ghIj"
Output: "j-Ih-gfE-dCba"

Example 3:

Input: s = "Test1ng-Leet=code-Q!"
Output: "Qedo1ct-eeLg=ntse-T!"

## Решение

Задача 917. Reverse Only Letters (Развернуть только буквы) — это отличный тест
на знание метода Двух указателей (Two Pointers). Она проверяет, насколько
аккуратно ты умеешь ставить условия для движения указателей.

## 🎯 Суть задачи

Тебе дана строка s. Нужно развернуть её символы в обратном порядке, но с одним
важным условием: все символы, которые не являются английскими буквами (знаки
препинания, цифры, дефисы), должны остаться строго на своих исходных местах.

Пример: s = "a-bC-dEf-ghIj"

Результат: "j-Ih-gfE-dCba"

Обрати внимание: дефисы - остались на тех же индексах, где и были, а буквы
плавно развернулись вокруг них.

## Суть решения: Встречные указатели с фильтрацией

Мы преобразуем строку в массив символов CharArray и поставим два указателя:

1. left на самый первый символ (индекс 0).
2. right на самый последний символ (индекс chars.size - 1).

Они будут двигаться навстречу друг другу:

* Если left указывает не на букву, он просто делает шаг вперед (left++),
  игнорируя этот символ.
* Если right указывает не на букву, он просто делает шаг назад (right--),
  игнорируя этот символ.
* Если оба указателя стоят на буквах, мы меняем эти буквы местами, а затем
  сдвигаем оба указателя к центру (left++, right--).

Для проверки, является ли символ английской буквой, в Kotlin есть очень удобный
встроенный метод Char.isLetter().

## Код на Kotlin

Вот лаконичное и максимально эффективное решение:

```kotlin
class Solution {
    fun reverseOnlyLetters(s: String): String {
        val chars = s.toCharArray()
        var left = 0
        var right = chars.size - 1

        while (left < right) {
            // 1. Если слева не буква, просто пропускаем её
            if (!chars[left].isLetter()) {
                left++
            }
            // 2. Если справа не буква, просто пропускаем её
            else if (!chars[right].isLetter()) {
                right--
            }
            // 3. Оба указателя на буквах — делаем обмен
            else {
                val temp = chars[left]
                chars[left] = chars[right]
                chars[right] = temp
                left++
                right--
            }
        }

        return String(chars)
    }

}

```

## Пошаговый разбор на примере s = "a-bC"

Переводим в массив: chars = ['a', '-', 'b', 'C'].
left = 0 (буква 'a'), right = 3 (буква 'C').

1. Шаг 1:

    * chars[left] ('a') — это буква.
    * chars[right] ('C') — это буква.
    * Срабатывает блок else. Меняем их местами.
    * Массив становится: ['C', '-', 'b', 'a'].
    * Сдвиг указателей: left становится 1, right становится 2.

2. Шаг 2:

    * left = 1 указывает на '-'.
    * Срабатывает самый первый if: !chars[left].isLetter().
    * Символ '-' не является буквой, поэтому мы просто делаем left++. left
      становится равен 2.

3. Шаг 3:

    * Теперь left = 2 (указывает на 'b') и right = 2 (указывает на 'b').
    * Условие цикла while (left < right) больше не выполняется (2 < 2 — ложь).

Цикл завершается, функция возвращает "C-ba".

## Сложность

* Времени: O(N) — мы проходим по строке один раз. Каждый символ проверяется
  указателями не более одного раза.
* Памяти: O(N) — нам нужен массив CharArray размером с исходную строку, чтобы
  изменять символы на месте.
