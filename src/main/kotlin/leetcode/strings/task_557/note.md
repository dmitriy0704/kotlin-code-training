# 557. Reverse Words in a String III

## Условие

Дана строка s. Необходимо изменить порядок символов в каждом слове предложения
на обратный, сохранив при этом пробелы и исходный порядок слов.

Example 1:

Input: s = "Let's take LeetCode contest"
Output: "s'teL ekat edoCteeL tsetnoc"

Example 2:

Input: s = "Mr Ding"
Output: "rM gniD"

## Решение

Задача 557. Reverse Words in a String III — это прекрасное продолжение темы двух
указателей и работы со строками.

## Суть задачи

Тебе дана строка s. Нужно развернуть порядок букв в каждом отдельном слове
внутри строки, но при этом сохранить исходный порядок самих слов и все пробелы.

Пример: s = "Let's take LeetCode contest"

Результат: "s'teL ekat edoCteeL tsetnoc"

## Два подхода к решению

В Kotlin эту задачу можно решить двумя путями: «ленивым» встроенным методом и
классическим алгоритмическим (через указатели).

## Способ 1: Kotlin-стиль (в одну строчку)

Мы можем разбить строку на слова по пробелам, развернуть каждое слово встроенной
функцией reversed(), а затем склеить их обратно через пробел.

```kotlin

class Solution {
    fun reverseWords(s: String): String {
        return s.split(" ").joinToString(" ") { it.reversed() }
    }
}

```

* Плюс: Пишется за 5 секунд.
* Минус: Создает много промежуточных объектов в памяти (split создает список
  строк, reversed — новые строки), что не очень любят на собеседованиях.

## Способ 2: Алгоритмический (Два указателя — Оптимально)

Чтобы сэкономить память, мы превращаем строку в массив символов CharArray. Мы
будем бежать по нему указателем right. Как только right натыкается на пробел или
доходит до конца строки, это означает, что мы только что прошли целое слово.
Мы берем начало этого слова (left) и его конец (right - 1) и разворачиваем
символы прямо на месте внутри массива.

## Оптимальный код на Kotlin

Вот решение, которое работает максимально быстро и эффективно:

```kotlin

class Solution {
    fun reverseWords(s: String): String {
        val chars = s.toCharArray()
        var left = 0 // Начало текущего слова

        for (right in 0..chars.size) {
            // Если дошли до пробела ИЛИ до самого конца строки — слово закончилось
            if (right == chars.size || chars[right] == ' ') {
                // Разворачиваем найденное слово от left до right - 1
                var start = left
                var end = right - 1

                while (start < end) {
                    val temp = chars[start]
                    chars[start] = chars[end]
                    chars[end] = temp
                    start++
                    end--
                }

                // Следующее слово начнется сразу после текущего пробела
                left = right + 1
            }
        }

        return String(chars)
    }

}


```

## Пошаговый разбор на маленьком примере: s = "Hi ya"

Превращаем в массив символов: chars = ['H', 'i', ' ', 'y', 'a']. Длина равна 5.
left изначально равен 0.

1. right = 0: символ 'H'. Не пробел.
2. right = 1: символ 'i'. Не пробел.
3. right = 2: символ ' ' (пробел!). Условие if сработало.

   * start = 0 (указывает на 'H'), end = 2 - 1 = 1 (указывает на 'i').
   * Цикл while меняет их местами. Слово "Hi" превратилось в "iH".
   * Массив стал: ['i', 'H', ' ', 'y', 'a'].
   * Обновляем left = right + 1 = 3 (теперь left указывает на букву 'y').

4. right = 3: символ 'y'. Не пробел.
5. right = 4: символ 'a'. Не пробел.
6. right = 5: (right == chars.size). Конец строки! Условие if снова сработало.

   * start = 3 (буква 'y'), end = 5 - 1 = 4 (буква 'a').
   * Меняем их местами. Слово "ya" превратилось в "ay".
   * Массив стал: ['i', 'H', ' ', 'a', 'y'].

Цикл завершен. Метод превращает массив обратно в строку и возвращает "iH ay".

## Сложность

* Времени: O(N) — мы один раз проходим по всей строке указателем right, а
  внутренний цикл while суммарно за все итерации развернет каждый символ ровно
  один раз.
* Памяти: O(N) — выделяется память под один массив CharArray, чтобы изменить
  символы. Больше никаких лишних списков и подстрок в памяти не создается.
