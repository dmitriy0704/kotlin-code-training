## Теория для решения задач на строки в Kotlin (LeetCode)

При решении задач на строки важно знать не только синтаксис Kotlin, но и
эффективные алгоритмические подходы. Ниже – краткий, но ёмкий набор теории и
практических приёмов.

---

### 1. Базовые свойства строк в Kotlin

- **Неизменяемость** – любая операция, изменяющая содержимое, создаёт новую
  строку. Для частых модификаций используйте `StringBuilder` или `CharArray`.
- **Доступ по индексу** – `s[i]` (только чтение), индексы от `0` до `length-1`.
- **Сравнение** – `==` сравнивает содержимое (как `equals`), `===` – ссылки.
- **Преобразования** – `.toCharArray()`, `.toByteArray()`, `.toInt()` (если
  строка – число).

---

### 2. Полезные функции стандартной библиотеки

| Функция                           | Описание                                              |
|-----------------------------------|-------------------------------------------------------|
| `substring(start, end)`           | Вырезает подстроку.                                   |
| `slice(range)`                    | Аналог `substring`.                                   |
| `reversed()`                      | Переворачивает строку (создаёт новую).                |
| `split(Regex/Char)`               | Разбивает на список.                                  |
| `joinToString()`                  | Собирает коллекцию в строку с разделителем.           |
| `groupBy { it }`                  | Группирует символы (полезно для анаграмм).            |
| `count { условие }`               | Подсчёт символов по условию.                          |
| `indexOf(char)` / `lastIndexOf`   | Поиск позиции.                                        |
| `replace(old, new)`               | Замена символов или подстрок.                         |
| `filter { условие }`              | Оставляет только подходящие символы.                  |
| `map { ... }`                     | Преобразует каждый символ.                            |
| `fold(initial) { acc, c -> ... }` | Сворачивание (аналог `reduce` с начальным значением). |
| `associateWith { ... }`           | Строит словарь (ключ – символ, значение – результат). |
| `toHashSet()` / `toSet()`         | Для проверки уникальности.                            |

**Важно:** многие из этих функций создают новые коллекции/строки – используйте
их с умом для коротких строк; для больших объёмов предпочитайте итеративные
подходы с `CharArray`.

### 3. Часто используемые паттерны решения

#### 3.1. Два указателя (Two Pointers)

- Применяется для палиндромов, поиска подстрок, обратного прохода.
- Пример: проверка палиндрома:

```kotlin
fun isPalindrome(s: String): Boolean {
    var l = 0;
    var r = s.length - 1
    while (l < r) {
        if (s[l++] != s[r--]) return false
    }
    return true
}
```

- Часто требуется пропускать небуквенные символы (используйте
  `Char.isLetterOrDigit()`).

#### 3.2. Скользящее окно (Sliding Window)

- Для задач на подстроки с ограничениями (например, "самая длинная подстрока без
  повторяющихся символов").
- Поддерживаем множество/счётчик символов в окне, сдвигаем правую границу, при
  нарушении – левую.
- Примерный каркас:

```kotlin
val set = mutableSetOf<Char>()
var left = 0;
var maxLen = 0
for (right in s.indices) {
    while (s[right] in set) set.remove(s[left++])
    set.add(s[right])
    maxLen = maxOf(maxLen, right - left + 1)
}
```

#### 3.3. Хеш-таблицы (словари, множества)

- Для поиска анаграмм, подсчёта частот, проверки уникальности.
- Используйте `mutableMapOf<Char, Int>()` или массив из 26 (для латиницы).
- Классика: "Перестановка строк", "Группировка анаграмм".

#### 3.4. Динамическое программирование (DP)

- Для задач на подпоследовательности (например, "наибольшая общая
  подпоследовательность", "редакционное расстояние").
- Обычно используется двумерный массив `dp[i][j]`, где `i` и `j` – позиции в
  строках.
- В Kotlin можно использовать `Array(size) { IntArray(size) }`.

#### 3.5. Префиксные суммы / хеши

- Для быстрого сравнения подстрок (роллинг-хеш) или подсчёта количества
  вхождений.
- Постройте массив префиксных сумм для быстрого получения хеша подстроки (
  например, для поиска повторяющихся строк).

#### 3.6. Поиск подстроки (KMP, Z-функция, Rabin-Karp)

- В Kotlin есть встроенный `indexOf` (использующий оптимизированный алгоритм).
  Но для понимания задач может потребоваться реализация KMP.
- KMP строится на префикс-функции – полезно для "поиска вхождения", "
  повторяющейся подстроки".

### 4. Особенности Kotlin, которые упрощают код

- **Деструктуризация** – `val (a, b) = pair`, но чаще используют `withIndex()`.
- **Функции расширения** – пишите свои `.isPalindrome()` и т.п.
- **Удобные операции с символами** – `c.isDigit()`, `c.isLetter()`,
  `c.toInt()` (преобразование в цифру), `c + 1` для сдвига.
- **Работа с регулярками** – `Regex("pattern")` для сложных замен.
- **Строковые шаблоны** – `"$var"` для построения результата.

---

### 5. Советы по производительности

- Если нужно много раз добавлять символы, используйте `StringBuilder`:

```kotlin
val sb = StringBuilder()
sb.append('a')
sb.append("bc")
return sb.toString()
```

- Для замены символов по индексу – создайте `CharArray`:

```kotlin
val arr = s.toCharArray()
arr[i] = 'x'
return String(arr)
```

- Избегайте `s.substring(1) + s[0]` для больших строк – это O(n) каждый раз.
- Для подсчёта частот в строке, содержащей только латиницу, используйте массив
  `IntArray(26)` – это быстрее словаря.
- При сравнении подстрок сначала проверяйте длины, затем символы в цикле.

### 6. Типовые задачи на LeetCode для отработки

- **Палиндромы** – `125. Valid Palindrome`, `5. Longest Palindromic Substring` (
  DP или расширение центра).
- **Анаграммы** – `242. Valid Anagram`, `49. Group Anagrams`.
- **Подстроки без повторов** –
  `3. Longest Substring Without Repeating Characters` (скользящее окно).
- **Поиск и замена** – `28. Find the Index of the First Occurrence` (KMP или
  встроенный `indexOf`).
- **Общие подпоследовательности** – `1143. Longest Common Subsequence` (DP).
- **Редакционное расстояние** – `72. Edit Distance`.
- **Преобразования** – `6. Zigzag Conversion`, `8. String to Integer (atoi)`.
- **Шифрование/декодирование** – `271. Encode and Decode Strings` (для практики
  работы с разделителями).

### 7. Полезные сниппеты на Kotlin

```kotlin
// Быстрое обращение
fun String.isPalindrome(): Boolean = this == this.reversed()

// Подсчёт частот в виде карты
fun String.freqMap(): Map<Char, Int> = this.groupingBy { it }.eachCount()

// Проверка, что строка содержит только уникальные символы (без доп. памяти)
fun String.allUnique(): Boolean {
    val seen = mutableSetOf<Char>()
    return this.all { seen.add(it) }
}

// Сравнение после удаления небуквенных
fun String.clean(): String = this.filter { it.isLetterOrDigit() }.lowercase()

// Генерация всех подстрок (для маленьких строк)
fun String.allSubstrings(): List<String> =
    indices.flatMap { i -> (i + 1..length).map { j -> substring(i, j) } }
```

### 8. Важно помнить

- В Kotlin строки — это последовательности UTF-16, но для задач LeetCode обычно
  достаточно работы с `Char`.
- При использовании `split` с несколькими разделителями передавайте `Regex`,
  например `split(Regex("[ ,.!]"))`.
- Для эффективного перебора символов используйте `for (c in s)` или
  `for (i in s.indices)`.
