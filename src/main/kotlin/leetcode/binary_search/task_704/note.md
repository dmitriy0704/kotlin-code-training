# 704. Binary Search

## Условие

Дан массив целых чисел nums, отсортированный в порядке возрастания, и целое
число target. Напишите функцию для поиска target в массиве nums. Если target
существует, верните его индекс. В противном случае верните -1.

Вам необходимо написать алгоритм со сложностью выполнения O(log n).

Example 1:

Input: nums = [-1,0,3,5,9,12], target = 9
Output: 4
Explanation: 9 exists in nums and its index is 4

Example 2:

Input: nums = [-1,0,3,5,9,12], target = 2
Output: -1
Explanation: 2 does not exist in nums so return -1

## Решение

Задача 704. Binary Search (Бинарный поиск) — это абсолютная база алгоритмов. Она
открывает дверь к целому семейству задач, которые работают по принципу «разделяй
и властвуй».

## 🎯 Суть задачи

Тебе дан массив целых чисел nums, который уже отсортирован по возрастанию, и
целевое число target.

Нужно найти индекс числа target в этом массиве. Если число есть — вернуть его
индекс, если его нет — вернуть -1.

Главное условие LeetCode: алгоритм должен работать за время $O(\log N)$. Это
значит, что просто пройтись по массиву обычным циклом for (что заняло бы $O(N)$)
нельзя.

## Суть решения: Игра «Загадай число»

Вспомни, как люди играют в угадывание чисел от 1 до 100. Если ты назовешь 50, а
тебе скажут «мало», ты мгновенно отбросишь все числа от 1 до 50. Твой диапазон
поиска сократится ровно в два раза.
Бинарный поиск делает именно это:

1. Мы берем две границы: left (начало массива) и right (конец массива).
2. Находим середину диапазона: pivot = (left + right) / 2.
3. Сравниваем элемент на этой середине с нашим target:

    * Если угадали — возвращаем индекс pivot.
    * Если элемент на середине больше target — значит, всё, что правее этой
      середины, нам точно не подходит. Мы сдвигаем правую границу: right =
      pivot - 1.
    * Если элемент на середине меньше target — значит, вся левая половина нам не
      нужна. Мы сдвигаем левую границу: left = pivot + 1.

4. Повторяем, пока left не перешагнет через right.

## Код на Kotlin

Вот классическая и безопасная реализация бинарного поиска:

```kotlin

class Solution {
    fun search(nums: IntArray, target: Int): Int {
        var left = 0
        var right = nums.size - 1

        while (left <= right) {
            // Находим середину. 
            // Формула left + (right - left) / 2 защищает от переполнения Int 
            // в отличие от старого варианта (left + right) / 2
            val pivot = left + (right - left) / 2

            if (nums[pivot] == target) {
                return pivot // Нашли! Возвращаем индекс
            }

            if (nums[pivot] > target) {
                right = pivot - 1 // Ищем в левой половине
            } else {
                left = pivot + 1  // Ищем в правой половине
            }
        }

        // Если вышли из цикла, значит target в массиве нет
        return -1
    }

}

```

## Пошаговый разбор на примере: nums = [-1, 0, 3, 5, 9, 12], target = 9

1. Итерация 1:

    * left = 0, right = 5.
    * pivot = 0 + (5 - 0) / 2 = 2. Узел под индексом 2 — это число 3.
    * Проверяем: 3 == 9? Нет. 3 < 9, значит число 9 находится правее.
    * Сдвигаем левую границу: left = pivot + 1 = 3.

2. Итерация 2:

    * left = 3, right = 5.
    * pivot = 3 + (5 - 3) / 2 = 4. Узел под индексом 4 — это число 9.
    * Проверяем: 9 == 9? Да!
    * Функция мгновенно возвращает индекс 4.

Заметь: в массиве из 6 элементов мы нашли число всего за 2 шага вместо 5 при
обычном переборе. Если бы в массиве было 1 000 000 элементов, обычный поиск мог
бы занять до миллиона шагов, а бинарный справился бы максимум за 20
шагов ($2^{20} \approx 10^6$).

## Сложность

* Времени: O(\log N) — на каждом шаге мы уменьшаем область поиска ровно в два
  раза.
* Памяти: O(1) — мы завели всего три числовые переменные для индексов.
