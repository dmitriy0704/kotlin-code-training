# 704. Binary Search

## Условие

Дан массив целых чисел nums, отсортированный в порядке возрастания, и целое
число target. Напишите функцию для поиска target в массиве nums. Если target
существует, верните его индекс. В противном случае верните -1.

Вам необходимо написать алгоритм со сложностью выполнения O(log n).

Example 1:

Input: nums = [-1,0,3,5,9,12], target = 9
Output: 4
Explanation: 9 exists in nums and its index is 4

Example 2:

Input: nums = [-1,0,3,5,9,12], target = 2
Output: -1
Explanation: 2 does not exist in nums so return -1

## Условие задачи

> Дан **отсортированный** по возрастанию массив целых чисел `nums` и целое число
`target`.  
> Напишите функцию, которая возвращает **индекс** `target` в массиве, если он
> там есть, иначе `-1`.

Пример:  
`nums = [-1,0,3,5,9,12]`, `target = 9` → вывод `4`.

---

## Идея бинарного поиска

Мы используем тот факт, что массив отсортирован. Вместо линейного просмотра мы
каждый раз смотрим на **средний** элемент и отбрасываем половину массива:

- Если средний равен `target` → мы нашли ответ.
- Если средний **меньше** `target` → все элементы слева от среднего тоже
  меньше (поскольку массив отсортирован), значит, искомый индекс находится *
  *правее**. Отбрасываем левую половину.
- Если средний **больше** `target` → все элементы справа больше, значит, ищем *
  *левее**. Отбрасываем правую половину.

Каждый шаг уменьшает область поиска вдвое, поэтому сложность — **O(log n)**, где
`n` — длина массива.

---

## Детали реализации на Kotlin

### Выбор границ и условия цикла

Мы будем использовать **замкнутый интервал** `[left, right]`, где `left` и
`right` — индексы, включительно.  
Инициализация: `left = 0`, `right = nums.size - 1`.

Цикл продолжается, пока `left <= right` — то есть пока интервал не пуст. Когда
`left > right`, значит, мы проверили все возможные позиции и не нашли `target`.

### Вычисление середины

Середина: `val mid = left + (right - left) / 2`  
Этот способ безопаснее, чем `(left + right) / 2`, потому что не вызывает
переполнения при больших значениях `left` и `right`.  
В Kotlin можно также использовать `(left + right) ushr 1` — это побитовый сдвиг
вправо, который эквивалентен делению на 2 для неотрицательных чисел.

### Сравнение и сужение интервала

```kotlin
when {
    nums[mid] == target -> return mid   // нашли
    nums[mid] < target -> left = mid + 1  // цель справа
    else -> right = mid - 1 // цель слева (nums[mid] > target)
}
```

- Если `nums[mid] < target`, то все элементы от `left` до `mid` включительно
  меньше `target`, поэтому мы смещаем `left` на `mid + 1`.
- Если `nums[mid] > target`, то все элементы от `mid` до `right` включительно
  больше `target`, поэтому сдвигаем `right` на `mid - 1`.

### Завершение

Если цикл завершился (т.е. `left > right`), значит, `target` в массиве нет —
возвращаем `-1`.

## Полный код (Kotlin)

```kotlin
class Solution {
    fun search(nums: IntArray, target: Int): Int {
        var left = 0
        var right = nums.lastIndex  // или nums.size - 1

        while (left <= right) {
            val mid = left + (right - left) / 2
            when {
                nums[mid] == target -> return mid
                nums[mid] < target -> left = mid + 1
                else -> right = mid - 1
            }
        }
        return -1
    }
}
```

---

## Пошаговый пример

Возьмём `nums = [-1, 0, 3, 5, 9, 12]`, `target = 9`.

1. `left = 0`, `right = 5` → `mid = 0 + (5-0)/2 = 2` → `nums[2] = 3`  
   `3 < 9` → `left = 3`
2. Теперь `left = 3`, `right = 5` → `mid = 3 + (5-3)/2 = 4` → `nums[4] = 9`  
   `9 == 9` → возвращаем `4`.

Если бы искали `target = 2`:

1. `left=0, right=5, mid=2, nums[2]=3 > 2` → `right = 1`
2. `left=0, right=1, mid=0, nums[0]=-1 < 2` → `left = 1`
3. `left=1, right=1, mid=1, nums[1]=0 < 2` → `left = 2`
4. Теперь `left=2, right=1` → условие `left <= right` ложно, выходим, возвращаем
   `-1`.

## Альтернативный вариант: рекурсивная реализация

Хотя итеративная версия предпочтительнее (нет риска переполнения стека), для
полноты можно показать и рекурсивную:

```kotlin
fun search(
    nums: IntArray,
    target: Int,
    left: Int = 0,
    right: Int = nums.lastIndex
): Int {
    if (left > right) return -1
    val mid = left + (right - left) / 2
    return when {
        nums[mid] == target -> mid
        nums[mid] < target -> search(nums, target, mid + 1, right)
        else -> search(nums, target, left, mid - 1)
    }
}
```

---

## Важные нюансы и советы

- **Инвариант цикла**: на каждой итерации мы точно знаем, что если `target` есть
  в массиве, то его индекс лежит в интервале `[left, right]`. Это помогает
  избегать логических ошибок.
- **Проверка на пустой массив**: в коде выше, если `nums` пуст, `right = -1`, и
  цикл не выполнится, сразу вернётся `-1` — это корректно.
- **Стандартная функция Kotlin**: в Kotlin у массивов и списков есть встроенная
  `binarySearch()`, которая возвращает либо индекс, либо отрицательное значение
  `-insertionPoint - 1`. Но для тренировки лучше реализовать самим.
- **Другие варианты границ**: иногда используют полуоткрытый интервал
  `[left, right)` и условие `while (left < right)`. Это тоже рабочий подход, но
  для задачи 704 чаще используют замкнутый интервал, потому что он интуитивно
  понятнее и короче.
