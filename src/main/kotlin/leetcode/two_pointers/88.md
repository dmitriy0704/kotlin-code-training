# 88. Merge Sorted Array

## Условие

Вам даны два массива целых чисел nums1 и nums2, отсортированные в порядке
убывания, и два целых числа m и n, представляющие количество элементов в
массивах nums1 и nums2 соответственно.

Объедините массивы nums1 и nums2 в один массив, отсортированный в порядке
убывания.

Функция не должна возвращать отсортированный в итоге массив, а должна хранить
его внутри массива nums1. Для этого длина массива nums1 равна m + n, где первые
m элементов обозначают элементы, которые следует объединить, а последние n
элементов равны 0 и должны быть проигнорированы. Длина массива nums2 равна n.

Example 1:
Input: nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3
Output: [1,2,2,3,5,6]
Пояснение: Объединяемые массивы — [1,2,3] и [2,5,6]. Результатом объединения
станет массив [1,2,2,3,5,6], при этом подчеркнутые элементы взяты из массива
nums1.

Example 2:
Input: nums1 = [1], m = 1, nums2 = [], n = 0
Output: [1]
Пояснение: Объединяемые массивы — [1] и []. Результатом объединения будет [1].

Example 3:
Input: nums1 = [0], m = 0, nums2 = [1], n = 1
Output: [1]
Пояснение: Объединяемые массивы — [] и [1]. Результатом объединения
является [1]. Обратите внимание, что поскольку m = 0, в массиве nums1 нет
элементов. 0 присутствует только для того, чтобы результат объединения
поместился в nums1.
