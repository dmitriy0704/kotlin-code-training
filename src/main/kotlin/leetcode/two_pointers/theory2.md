# Алгоритм

Привет! Отличный выбор — техника **Two Pointers** (два указателя) — одна из
самых частых на Leetcode. Она простая, но мощная, и помогает решать задачи за
линейное время O(n) вместо O(n²). Расскажу, что нужно знать, чтобы уверенно
решать такие задачи на Kotlin.

## 1. Что такое два указателя?

Это метод, когда мы используем два индекса (или ссылки) для обхода структуры
данных (обычно массива или строки). Указатели двигаются по определённым
правилам, сужая область поиска или сравнивая элементы.

## 2. Основные сценарии использования

- **Массивы и строки** (чаще всего)
- **Отсортированные массивы** — классика для двух указателей с концов
- **Связные списки** (медленный/быстрый указатель)
- **Поиск подстрок, палиндромов, сумм, удаление дубликатов** и т.д.

## 3. Типичные паттерны двух указателей

### А) Один слева, другой справа (встречное движение)

Используется в **отсортированных** массивах или строках.  
Примеры: поиск пары с заданной суммой, проверка палиндрома, контейнер с
наибольшим количеством воды.

**Логика:**

- `left = 0`, `right = n - 1`
- пока `left < right`, сравниваем элементы и двигаем левый вправо или правый
  влево в зависимости от условия.

### Б) Оба указателя стартуют с начала (однонаправленное движение)

Часто используется для **разделения массива** (например, переместить все нули в
конец) или для **удаления дубликатов** в отсортированном массиве.

**Логика:**

- `slow` и `fast` начинаются с 0
- `fast` бежит вперёд, а `slow` отмечает позицию для записи, когда найдено
  подходящее значение.

### В) Быстрый и медленный (для циклов, поиска середины)

Применяется в связных списках, но иногда и в массивах (например, поиск цикла).

- `slow` двигается на 1 шаг, `fast` на 2 шага.

### Г) Скользящее окно — это тоже вариация двух указателей (обычно оба движутся в одну сторону, но с изменяемым расстоянием). Хотя это выделяют в отдельную тему, на Leetcode они часто пересекаются.

## 4. Что нужно знать в Kotlin для реализации

- **Объявление переменных**: `var left = 0`, `var right = nums.size - 1`
- **Циклы `while`** — основной инструмент: `while (left < right) { ... }`
- **Доступ к элементам** по индексу: `nums[left]`, `str[right]`
- **Функции** для строк: `str.length`, `str.get(index)`, `str.substring`
- **Работа с массивами**: `IntArray`, `size`, доступ по индексу
- **Обмен значениями** — если нужно, стандартный `temp`
- **Безопасный доступ** — всегда проверяйте границы, чтобы не выйти за пределы.

Хотя в Kotlin есть красивые функции вроде `withIndex()`, для двух указателей
чаще используют именно `while` с индексами, так проще контролировать движение.

## 5. Разбор нескольких классических задач с кодом

### Задача 1. Valid Palindrome (Leetcode 125)

Проверить, является ли строка палиндромом, игнорируя регистр и не
буквенно-цифровые символы.

**Подход:** два указателя с двух концов, пропускаем ненужные символы, сравниваем
буквы.

```kotlin
fun isPalindrome(s: String): Boolean {
    var left = 0
    var right = s.length - 1
    while (left < right) {
        while (left < right && !s[left].isLetterOrDigit()) left++
        while (left < right && !s[right].isLetterOrDigit()) right--
        if (s[left].lowercaseChar() != s[right].lowercaseChar()) return false
        left++
        right--
    }
    return true
}
```

### Задача 2. Two Sum II - Input Array Sorted (Leetcode 167)

Найти индексы (1-based) двух чисел в отсортированном массиве, дающих заданную
сумму.

**Подход:** левый и правый указатели. Если сумма слишком мала, двигаем левый
вправо; если велика — правый влево.

```kotlin
fun twoSum(numbers: IntArray, target: Int): IntArray {
    var left = 0
    var right = numbers.size - 1
    while (left < right) {
        val sum = numbers[left] + numbers[right]
        when {
            sum == target -> return intArrayOf(left + 1, right + 1)
            sum < target -> left++
            else -> right--
        }
    }
    return intArrayOf()
}
```

### Задача 3. Container With Most Water (Leetcode 11)

Найти две вертикальные линии, образующие контейнер с максимальным объёмом воды.

**Подход:** два указателя с концов. Высота ограничена меньшей из двух линий.
Сдвигаем указатель с меньшей высотой, чтобы попытаться увеличить объём.

```kotlin
fun maxArea(height: IntArray): Int {
    var left = 0
    var right = height.size - 1
    var maxArea = 0
    while (left < right) {
        val area = (right - left) * minOf(height[left], height[right])
        maxArea = maxOf(maxArea, area)
        if (height[left] < height[right]) left++ else right--
    }
    return maxArea
}
```

### Задача 4. Remove Duplicates from Sorted Array (Leetcode 26)

Удалить дубликаты на месте, вернуть новую длину.

**Подход:** медленный указатель `i` (место для вставки) и быстрый `j` (обход
всех элементов).

```kotlin
fun removeDuplicates(nums: IntArray): Int {
    if (nums.isEmpty()) return 0
    var i = 0
    for (j in 1 until nums.size) {
        if (nums[j] != nums[i]) {
            i++
            nums[i] = nums[j]
        }
    }
    return i + 1
}
```

Здесь мы использовали `for` вместо `while`, но это тоже техника двух
указателей (медленный и быстрый).

## 6. Советы по решению задач на Leetcode

- **Сортировка** — если массив не отсортирован, часто нужно отсортировать его
  перед применением двух указателей (но тогда теряются исходные индексы, если
  они важны).
- **Граничные условия** — всегда проверяйте `left < right`, чтобы не выйти за
  пределы. Осторожно с пустыми или одноэлементными массивами.
- **Избегайте бесконечных циклов** — при движении указателей они должны меняться
  строго (хотя бы на 1) на каждой итерации.
- **Вложенные циклы для пропуска дубликатов** — часто при решении `3Sum` нужно
  пропускать одинаковые элементы, чтобы не повторять тройки.
- **Сложность** — обычно O(n) по времени и O(1) по памяти (кроме случаев, когда
  нужна дополнительная структура).

## 7. Что ещё стоит изучить дополнительно

- **Три указателя** (например, для `3Sum`) — один фиксированный, два бегут с
  концов.
- **Скользящее окно** — часто считается отдельной темой, но по сути тоже два
  указателя.
- **Два указателя в связных списках** — для поиска середины, обнаружения цикла (
  алгоритм Флойда).
