# 80. Remove Duplicates from Sorted Array II

## Условие

Дан целочисленный массив nums, отсортированный в порядке неубывания. Необходимо
удалить некоторые дубликаты на месте таким образом, чтобы каждый уникальный
элемент встречался не более двух раз. Относительный порядок элементов должен
оставаться неизменным.

Поскольку в некоторых языках программирования невозможно изменить длину массива,
результат необходимо поместить в первую часть массива `nums`.
Более формально, если после удаления дубликатов осталось k элементов, то первые
k элементов массива nums должны содержать окончательный результат. Не имеет
значения, что останется после первых k элементов.

Return k after placing the final result in the first k slots of nums.

Не выделяйте дополнительное пространство для другого массива. Это необходимо
сделать путем модификации входного массива на месте с использованием
дополнительной памяти O(1).

Example 1:

Input: nums = [1,1,1,2,2,3]
Output: 5, nums = [1,1,2,2,3,_]
Пояснение: Ваша функция должна возвращать k = 5, причем первые пять элементов
nums должны быть 1, 1, 2, 2 и 3 соответственно. Не имеет значения, что вы
оставите после возвращаемого k (поэтому это символы подчеркивания).

Example 2:

Input: nums = [0,0,1,1,1,1,2,3,3]
Output: 7, nums = [0,0,1,1,2,3,3,_,_]
Пояснение: Ваша функция должна возвращать k = 7, причем первые семь элементов
nums равны 0, 0, 1, 1, 2, 3 и 3 соответственно. Не имеет значения, что вы
оставите после возвращаемого k (поэтому это символы подчеркивания).

Constraints:

1 <= nums.length <= 3 * 104
-104 <= nums[i] <= 104
nums is sorted in non-decreasing order.

## Решение

Отлично, переходим к задаче **80. Remove Duplicates from Sorted Array II** (
Удалить дубликаты из отсортированного массива, разрешено оставлять не более двух
одинаковых). Это логическое продолжение задачи 26, где можно было оставлять
только один экземпляр. Здесь ограничение — максимум два повторения подряд.

Твоя интуиция насчёт двух указателей абсолютно верна: используем медленный (
write) и быстрый (read). Но условие для записи меняется.

---

## Суть алгоритма

В задаче 26 мы сравнивали `nums[fast]` с `nums[slow-1]` (или с `nums[slow]`).
Теперь нам нужно разрешить **два одинаковых** элемента подряд. Поэтому мы должны
сравнивать текущий элемент с элементом, который находится **на две позиции назад
** от места записи (`nums[slow - 2]`). Если они отличаются — можем записывать.

- **Медленный указатель `i`** (он же `writePos`) — показывает позицию, куда
  будем вставлять следующий допустимый элемент. Изначально `i = 2`, потому что
  первые два элемента (индексы 0 и 1) всегда допустимы (даже если они равны, это
  два одинаковых, что разрешено).
- **Быстрый указатель `j`** (он же `readPos`) — пробегает по массиву, начиная с
  индекса 2, и ищет элементы, которые можно записать.

**Критерий записи:**  
Если `nums[j] != nums[i - 2]`, то мы можем записать `nums[j]` в `nums[i]` и
увеличить `i`.  
Почему это работает? Массив отсортирован, и если текущий элемент равен элементу,
который был записан на две позиции назад (т.е. в `i-2`), значит, в текущей
записанной части уже есть два таких элемента, и этот будет третьим — его
пропускаем.

---

## Реализация на Kotlin

```kotlin
fun removeDuplicates(nums: IntArray): Int {
    // Если длина <= 2, то все элементы уже допустимы
    if (nums.size <= 2) return nums.size

    var i = 2 // медленный указатель, начинаем с индекса 2
    for (j in 2 until nums.size) { // быстрый указатель
        if (nums[j] != nums[i - 2]) {
            nums[i] = nums[j]
            i++
        }
    }
    return i
}
```

---

## Пример работы

Вход: `[1,1,1,2,2,3]`

- `i = 2` (первые два элемента `[1,1]` уже допустимы)
- `j = 2`: `nums[2] = 1`, `nums[i-2] = nums[0] = 1` → равны → пропускаем (это
  третий '1').
- `j = 3`: `nums[3] = 2`, `nums[0] = 1` → не равны → записываем `nums[2] = 2`,
  `i = 3`.  
  Массив: `[1,1,2,2,2,3]`
- `j = 4`: `nums[4] = 2`, `nums[1] = 1` → не равны → записываем `nums[3] = 2`,
  `i = 4`.  
  Массив: `[1,1,2,2,2,3]`
- `j = 5`: `nums[5] = 3`, `nums[2] = 2` → не равны → записываем `nums[4] = 3`,
  `i = 5`.  
  Массив: `[1,1,2,2,3,3]` (первые 5 элементов: 1,1,2,2,3)  
  Возвращаем `5` — правильная длина.

## Альтернативный подход – счётчик повторений

Можно использовать переменную `count`, чтобы отслеживать, сколько раз текущее
значение уже было записано:

```kotlin
fun removeDuplicates(nums: IntArray): Int {
    var i = 0
    for (num in nums) {
        if (i < 2 || num != nums[i - 2]) {
            nums[i] = num
            i++
        }
    }
    return i
}
```

Этот вариант компактнее и не требует отдельного цикла с `j`. Здесь мы перебираем
все элементы, и если их уже два (или меньше), то записываем. Условие `i < 2`
гарантирует, что первые два элемента всегда попадут в результат.

## Сложность

- **Время:** O(n) — один проход.
- **Память:** O(1) — только переменные.

## Закрепление

Теперь у тебя есть два подхода:

1. Сравнение с `nums[i-2]` (как в задаче 26, но сдвиг на 2).
2. Счётчик повторений (более универсальный, если позже потребуется разрешить 3,
   4 и т.д. повторения).
