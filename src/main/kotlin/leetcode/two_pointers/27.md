# 27. Remove Element

## Условие

Дан массив целых чисел nums и массив целых чисел val. Необходимо удалить все
вхождения val из массива nums на месте. Порядок элементов может быть изменен.
Затем верните количество элементов в массиве nums, которые не равны val.

Рассмотрим количество элементов в массиве nums, которые не равны значению k. Для
того чтобы запрос был принят, необходимо выполнить следующие действия:

- Измените массив nums таким образом, чтобы первые k элементов содержали
  элементы, не равные val. Остальные элементы массива nums, а также размер
  массива nums, не имеют значения.
- Возвращаем k.

Пользовательский судья:

```code

int[] nums = [...]; // Input array
int val = ...; // Значение для удаления
int[] expectedNums = [...]; // Ожидаемый ответ правильной длины.
                            // Отсортировано, нет значений, равных val.

int k = removeElement(nums, val); // Вызывает вашу реализацию

assert k == expectedNums.length;
sort(nums, 0, k); // Отсортируйте первые k элементов числа nums.
for (int i = 0; i < actualLength; i++) {
    assert nums[i] == expectedNums[i];
}

```

Если все утверждения пройдут успешно, ваше решение будет принято.

Example 1:

Input: nums = [3,2,2,3], val = 3
Output: 2, nums = [2,2,_,_]
Пояснение: Ваша функция должна возвращать k = 2, при этом первые два элемента
массива nums равны 2.
Неважно, что вы оставите после возвращаемого значения k (поэтому это
подчеркивания).

Example 2:

Input: nums = [0,1,2,2,3,0,4,2], val = 2
Output: 5, nums = [0,1,4,0,3,_,_,_]
Пояснение: Ваша функция должна возвращать k = 5, причем первые пять элементов
массива nums должны содержать 0, 0, 1, 3 и 4.
Обратите внимание, что пять элементов могут быть возвращены в любом порядке.
Неважно, что вы оставите после возвращаемого значения k (поэтому это
подчеркивания).

Constraints:

0 <= nums.length <= 100
0 <= nums[i] <= 50
0 <= val <= 100

## Условие задачи

Дан массив `nums` и целое число `val`. Нужно удалить все элементы, равные `val`,
**на месте (in-place)**, и вернуть новую длину массива.  
Порядок оставшихся элементов **не важен** (можно менять их местами). Элементы
после новой длины игнорируются.  
Требуется O(1) дополнительной памяти.

Пример:

- Вход: `nums = [3,2,2,3]`, `val = 3` → выход: `2`, массив становится
  `[2,2,_,_]` (первые два элемента — 2).
- Вход: `nums = [0,1,2,2,3,0,4,2]`, `val = 2` → выход: `5`, массив может быть
  `[0,1,4,0,3,_,_,_]` (порядок не важен).

---

## Два указателя: медленный (write) и быстрый (read)

Это самый простой и интуитивный подход, аналогичный задаче 26, но с другим
критерием.

- **`i` (медленный)** — указывает на позицию, куда будем записывать следующий
  «допустимый» элемент (не равный `val`). Изначально `i = 0`.
- **`j` (быстрый)** — бежит по массиву от `0` до `n-1`, проверяя каждый элемент.

**Алгоритм:**

1. Для каждого `j` от 0 до `nums.size - 1`:

- Если `nums[j] != val`, то записываем `nums[j]` в позицию `nums[i]` и
  увеличиваем `i` на 1.
- Если `nums[j] == val`, просто пропускаем (не записываем).

2. После цикла `i` становится количеством элементов, не равных `val`. Возвращаем
   `i`.

**Важно:** Мы не удаляем элементы физически — просто перезаписываем первые `i`
позиций. Остаток массива остаётся как был, но новая длина равна `i`.

## Реализация на Kotlin

```kotlin
fun removeElement(nums: IntArray, `val`: Int): Int {
    var i = 0 // медленный указатель — место для вставки
    for (j in nums.indices) { // быстрый указатель
        if (nums[j] != `val`) {
            nums[i] = nums[j]
            i++
        }
    }
    return i
}
```

**Краткость и читаемость:** здесь мы используем `for (j in nums.indices)`, что
эквивалентно `for (j in 0 until nums.size)`. В Kotlin переменную `val` нужно
экранировать обратными кавычками, потому что это ключевое слово, но в коде мы
можем назвать её `value` или `target`, чтобы не путаться.

---

## Альтернативный подход – два указателя с разных концов (для минимизации перемещений)

Если `val` встречается редко, можно использовать встречные указатели, чтобы
сократить число перезаписей.

- `left = 0`, `right = nums.size - 1`
- Пока `left <= right`:
    - Если `nums[left] == val`, то меняем его с `nums[right]` и уменьшаем
      `right` (этот элемент мы «удаляем» в конец).
    - Иначе увеличиваем `left`.
- В конце `left` будет равно новой длине.

Этот подход сохраняет порядок только в той степени, в какой мы меняем местами,
но он может быть эффективнее, когда удаляемых элементов мало.

```kotlin
fun removeElement(nums: IntArray, `val`: Int): Int {
    var left = 0
    var right = nums.size - 1
    while (left <= right) {
        if (nums[left] == `val`) {
            nums[left] = nums[right]
            right--
        } else {
            left++
        }
    }
    return left
}
```

**Почему это работает?**  
Когда мы встречаем `val` слева, мы подменяем его на элемент справа (который
может быть тоже `val`, но тогда мы проверим его на следующей итерации). Правый
указатель сдвигается влево, «отбрасывая» удалённые элементы в хвост. В конце
`left` станет количеством элементов, не равных `val`.

---

## Сравнение двух подходов

| Подход              | Число перезаписей            | Сохранение порядка | Память |
|---------------------|------------------------------|--------------------|--------|
| Медленный+быстрый   | O(n) в худшем (все не равны) | Да                 | O(1)   |
| Встречные указатели | O(число удаляемых элементов) | Нет                | O(1)   |

Выбор зависит от того, важен ли порядок и частота `val`. В условии порядок не
важен, так что оба решения принимаются.

---

## Почему это in-place?

Мы не создаём новый массив. Все операции выполняются внутри исходного `nums`.
Используем только несколько переменных для индексов, память O(1).

---

## Частые ошибки

- Забыть увеличить `i` после записи.
- Использовать `while` без учёта изменения длины (например, при удалении не
  сдвигать элементы, а просто уменьшать счётчик).
- Не обрабатывать случай пустого массива (хотя цикл отработает корректно, `i`
  будет 0).
