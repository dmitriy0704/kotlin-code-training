# 100. Same Tree

## Условие

Даны корни двух бинарных деревьев p и q. Напишите функцию для проверки того,
совпадают ли они.

Два бинарных дерева считаются одинаковыми, если они структурно идентичны, и узлы
имеют одинаковое значение.

Example 1:

Input: p = [1,2,3], q = [1,2,3]
Output: true

Example 2:

![ex2.jpg](../../../../../../imgs/ex_100_2.jpg)
Input: p = [1,2], q = [1,null,2]

## Решение

Задача 100. Same Tree (Одинаковые деревья) — это классическая задача на работу с
бинарными деревьями. Она идеально подходит для понимания рекурсии и обхода
деревьев вглубь (DFS).

## Суть задачи

Тебе даны корни двух бинарных деревьев p и q. Нужно написать функцию, которая
проверит, являются ли эти деревья абсолютно идентичными.
Деревья считаются одинаковыми, если:

1. Они имеют строго одинаковую структуру (форму).
2. Узлы на одних и тех же позициях содержат одинаковые значения.


## Суть рекурсивного решения

Дерево состоит из узла и двух поддеревьев (левого и правого). Значит, два дерева
равны, если равны их текущие узлы, а также равны их левые и правые ветки.
Мы можем проверить это с помощью трех простых базовых правил (условий выхода из
рекурсии):

1. Если оба узла null — значит, мы дошли до конца веток одновременно. Это
   истина (true).
2. Если один узел null, а другой нет — структура деревьев отличается. Это ложь (
   false).
3. Если значения в текущих узлах не совпадают — деревья разные. Это ложь (
   false).

Если текущие узлы прошли все проверки (оба не null и их значения равны), мы
запускаем эту же проверку для их левых детей и для их правых детей.

## Код на Kotlin

В Kotlin это решение пишется невероятно лаконично и красиво благодаря smart
cast (умному приведению типов) после проверок на null:

```kotlin
class TreeNode(var `val`: Int) {
    var left: TreeNode? = null
    var right: TreeNode? = null
}
class Solution {
    fun isSameTree(p: TreeNode?, q: TreeNode?): Boolean {
// 1. Если оба узла null, то на этом этапе они одинаковы
        if (p == null && q == null) return true

        // 2. Если один из них null, а второй нет — структура разная
        if (p == null || q == null) return false

        // 3. Если значения в узлах не равны — деревья разные
        if (p.`val` != q.`val`) return false

        // 4. Рекурсивно проверяем левые поддеревья И правые поддеревья
        // (Оба условия должны вернуть true)
        return isSameTree(p.left, q.left) && isSameTree(p.right, q.right)
    }
}

```


## Пример работы алгоритма

Представь два дерева:

* Дерево P: 1 -> левый ребенок 2, правый 3
* Дерево Q: 1 -> левый ребенок 2, правый 3


1. Вызывается isSameTree(p, q) для корней. Оба узла содержат 1. Проверки на null
   и неравенство значений пропускаются.
2. Программа идет проверять левую ветку: isSameTree(p.left, q.left) (сравнивает
   узлы с 2). Они равны.
3. Узлы 2 пытаются проверить своих детей (у них они оба null). Вызовы
   isSameTree(null, null) возвращают true.
4. Левая ветка полностью подтвердила равенство.
5. Программа идет проверять правую ветку от корня: isSameTree(p.right,
   q.right) (узлы с 3). Они тоже подтверждают равенство.
6. В итоге выполняется true && true, и функция выдает финальный true.

## Сложность

* Времени: O(N) — в худшем случае (когда деревья одинаковые) нам придется
  посетить абсолютно каждый узел в обоих деревьях. Здесь N — это количество
  узлов в меньшем из деревьев.
* Памяти: O(H) — где H — высота дерева. Память тратится на стек вызовов
  рекурсии. В самом худшем случае (если дерево выродилось в длинную прямую
  ветку) это будет O(N).
