# 101. Symmetric Tree

## Условие

Имея корень бинарного дерева, проверьте, является ли он зеркальным отражением
самого себя (то есть симметричен относительно своего центра).

Example 1:
![ex_101_1.jpg](../../../../../../imgs/ex_101_1.jpg)

Input: root = [1,2,2,3,4,4,3]
Output: true

Example 2:
![ex_101_2.jpg](../../../../../../imgs/ex_101_2.jpg)

Input: root = [1,2,2,null,3,null,3]
Output: false

## Решение

Задача 101. Symmetric Tree (Симметричное дерево) — это прямое 
продолжение задачи 100.

Здесь нас просят проверить, является ли дерево зеркальным отражением самого
себя, если посмотреть на него через центральную вертикальную ось.

## Визуальная суть задачи

Посмотри на эти два примера:
Пример 1: Симметричное дерево (true)

```text
     1
   /   \
  2     2
 / \   / \
3   4 4   3

```

Если сложить это дерево пополам по центру, левая половинка идеально совпадет с
правой. Узел 3 слева зеркально отражает узел 3 справа.

Пример 2: Несимметричное дерево (false)

```text
     1
   /   \
  2     2
   \     \
    3     3

```

Здесь у левой двойки есть только правый ребенок, а у правой двойки — тоже
правый. Зеркальности нет (у правой двойки должен быть левый ребенок, чтобы они
отражали друг друга).

## 💡 Как свести задачу к предыдущей?

Дерево симметрично, если его левое поддерево зеркально равно его правому
поддереву.
Мы можем создать вспомогательную функцию, которая принимает два узла (назовем их
leftTree и rightTree) и сравнивает их точно так же, как в задаче 100, но с одним
ключевым «зеркальным» изменением:

* Вместо сравнения left с left и right с right (как в задаче 100), мы должны
  сравнивать:

    1. Левого ребенка левого дерева с правым ребенком правого дерева.
    2. Правого ребенка левого дерева с левым ребенком правого дерева.

## Код на Kotlin

Вот лаконичное рекурсивное решение:

```kotlin

class Solution {
    fun isSymmetric(root: TreeNode?): Boolean {
// Пустое дерево всегда симметрично
        if (root == null) return true

        // Запускаем зеркальную проверку для левой и правой ветки корня
        return isMirror(root.left, root.right)
    }

    private fun isMirror(t1: TreeNode?, t2: TreeNode?): Boolean {
        // Базовые случаи (точно такие же, как в задаче 100)
        if (t1 == null && t2 == null) return true
        if (t1 == null || t2 == null) return false
        if (t1.`val` != t2.`val`) return false

        // Главная фишка: проверяем зеркальность внешних и внутренних веток
        // t1.left сравниваем с t2.right (внешние стороны)
        // t1.right сравниваем с t2.left (внутренние стороны)
        return isMirror(t1.left, t2.right) && isMirror(t1.right, t2.left)
    }

}


```

## Пошаговый разбор зеркального шага

Представь, что мы проверяем уровень с двойками из Симметричного дерева (Пример
1):

* t1 — это левая двойка, t2 — это правая двойка. Их значения равны (2 == 2).
* Программа делает первый рекурсивный вызов: isMirror(t1.left, t2.right). Она
  отправляет на проверку левого ребенка первой двойки (это 3) и правого ребенка
  второй двойки (это тоже 3). Они совпадают.
* Программа делает второй вызов: isMirror(t1.right, t2.left). Она отправляет
  правого ребенка первой двойки (4) и левого ребенка второй двойки (4). Они тоже
  совпадают.
* Оба вызова вернули true, значит, этот уровень симметричен.

## 📊 Сложность

* Времени: O(N) — мы обходим все узлы дерева ровно один раз.
* Памяти: O(H) — память в стеке для рекурсии, где H — высота дерева.

Эту задачу также можно решить без рекурсии (через цикл while и структуру Queue),
имитируя обход в ширину.
