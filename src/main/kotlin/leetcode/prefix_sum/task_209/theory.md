# Суть алгоритма

Скользящее окно (Sliding Window) — это мощный и элегантный алгоритмический
приём, который превращает медленный перебор элементов (за $O(N^2)$ или $O(N^3)$)
в быстрый одиночный проход по массиву за $O(N)$.
Его используют, когда нужно найти какую-то характеристику (максимальную сумму,
минимальную длину, уникальные символы) среди непрерывных подмассивов или
подстрок.
------------------------------

## 🗺️ Главная идея: Хватит считать заново!

Представь, что у тебя есть массив из 1000 элементов и тебе нужно найти
максимальную сумму среди всех кусочков длиной в 3 элемента.

* Плохой подход (Брутфорс):
  Ты считаешь сумму первых трех элементов (0 + 1 + 2). Потом переходишь к
  следующим трем (1 + 2 + 3) и складываешь их заново. Затем (2 + 3 + 4). Обрати
  внимание: элементы 1 и 2 ты складываешь повторно! На больших массивах
  компьютер будет делать миллиарды лишних сложений.
* Подход Скользящего окна:
  Ты берешь «раму» (окно) размером в 3 элемента. Посчитав сумму первого окна,
  чтобы узнать сумму следующего, тебе не нужно складывать всё заново. Достаточно
  сделать два действия:

1. Вычесть элемент, который «выпал» из окна слева.
    2. Добавить элемент, который «зашел» в окно справа.

Окно просто «скользит» по массиву, как объектив камеры.
------------------------------

## 🧱 Два типа скользящего окна

В зависимости от условий задачи, окна бывают двух видов:

## 1. Окно фиксированного размера

Размер окна строго задан в условии (например, «найти максимальную сумму
подмассива длины K»).

* Как работает: Мы сначала собираем окно размера K. Затем в цикле двигаем его
  вперед на 1 шаг: добавляем элемент справа, убираем слева.
* Пример задачи: Найти среднее арифметическое всех подмассивов размера K.

## 2. Окно динамического (динамически меняющегося) размера

Размер окна постоянно расширяется или сжимается в зависимости от выполнения
условий (как в задаче 209, которую мы решали).

* Как работает:
* Правый указатель (right) расширяет окно, пока мы не добьемся нужного условия.
    * Как только условие выполнено, левый указатель (left) начинает сжимать
      окно, чтобы найти самое оптимальное (например, минимальное) решение.
* Пример задачи: Найти самую длинную подстроку без повторяющихся символов.

------------------------------

## 💡 Как сразу узнать задачу на Скользящее окно?

В тексте задачи на LeetCode почти всегда есть три маркерных знака:

1. Имеет дело с линейными структурами (массив, строка, связный список).
2. Требует найти непрерывный подмассив или подстроку (subarray, substring).
3. Просит найти минимум, максимум или точное совпадение по какому-то критерию (
   Target sum, Longest, Shortest).

------------------------------

## 🛠️ Универсальный шаблон кода (для динамического окна)

Если ты пишешь решение на Kotlin, структура кода для динамического окна почти
всегда будет выглядеть одинаково:

```kotlin
fun slidingWindowTemplate(nums: IntArray, target: Int): Int {
    var left = 0
    var result = 0 // или Int.MAX_VALUE в зависимости от задачи
    var currentCondition = 0 // например, текущая сумма или счетчик

    for (right in nums.indices) {
        // 1. Расширяем окно: добавляем правый элемент в расчеты
        currentCondition += nums[right]

        // 2. Пока условие внутри окна выполняется — сжимаем его слева
        while (currentCondition >= target) { // Твое условие
            // Обновляем наш глобальный ответ (находим min или max длину)
            result = maxOf(result, right - left + 1)

            // Убираем левый элемент и двигаем левую границу
            currentCondition -= nums[left]
            left++
        }
    }
    return result

}
```
