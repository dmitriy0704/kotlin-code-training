# 560. Subarray Sum Equals K

# Условие

Дан массив целых чисел nums и целое число k. Верните общее количество
подмассивов, сумма элементов которых равна k.

Подмассив — это непрерывная непустая последовательность элементов внутри
массива.

Example 1:
Input: nums = [1,1,1], k = 2
Output: 2

Example 2:
Input: nums = [1,2,3], k = 3
Output: 2

Constraints:

1 <= nums.length <= 2 * 10^4
-1000 <= nums[i] <= 1000
-10^7 <= k <= 10^7

# Решение

## Задача

Дан массив целых чисел `nums` и целое число `k`.  
Нужно найти **количество непрерывных подмассивов**, сумма которых равна `k`.  
Массив может содержать отрицательные числа.

---

## Ключевая идея

Вводим понятие **префиксной суммы** `prefix[i]` – сумма элементов от начала
массива до индекса `i` включительно.

Для любого подмассива от индекса `j+1` до `i` (включительно) его сумма равна:

```
sum(j+1 .. i) = prefix[i] - prefix[j]
```

Чтобы эта сумма была равна `k`, нужно, чтобы `prefix[j] = prefix[i] - k`.

Таким образом, идя по массиву слева направо, мы накапливаем текущую сумму
`currentSum` (это и есть `prefix[i]`).  
На каждом шаге мы ищем, сколько раз ранее встречалась сумма `currentSum - k`.
Каждое такое совпадение даёт один подмассив, заканчивающийся в текущей позиции.

Для быстрого поиска используем хеш-таблицу (словарь), где ключ – значение
префиксной суммы, значение – сколько раз она встречалась.

**Важный нюанс:** изначально кладём в словарь `{0: 1}` – это пустой префикс (
сумма до начала массива). Он нужен, чтобы учитывать подмассивы, начинающиеся с
индекса 0.

---

## Алгоритм (пошагово)

1. Создаём переменную `count = 0` – ответ.
2. Создаём переменную `currentSum = 0` – текущая префиксная сумма.
3. Создаём словарь `map: MutableMap<Int, Int>` и инициализируем его как
   `map[0] = 1`.
4. Проходим по массиву, для каждого числа `num`:

- `currentSum += num`
- Вычисляем `target = currentSum - k`
- Если `map` содержит ключ `target`, прибавляем его значение к `count`.
- Увеличиваем значение для ключа `currentSum` в `map` на 1 (если ключа нет,
  создаём его со значением 1).

5. Возвращаем `count`.

---

## Сложность

- **Время:** O(n), где n – длина массива. Один проход, операции с хеш-таблицей в
  среднем O(1).
- **Память:** O(n) в худшем случае для хранения уникальных префиксных сумм.

---

## Реализация на Kotlin

```kotlin
class Solution {
    fun subarraySum(nums: IntArray, k: Int): Int {
        var count = 0
        var currentSum = 0
        // Словарь: префиксная сумма -> количество её появлений
        val prefixSumCount = mutableMapOf<Int, Int>()
        // Пустой префикс (сумма 0) встречается один раз до начала массива
        prefixSumCount[0] = 1

        for (num in nums) {
            currentSum += num

            // Нам нужно найти, сколько раз ранее встречалась сумма (currentSum - k)
            val target = currentSum - k
            count += prefixSumCount[target] ?: 0

            // Запоминаем текущую префиксную сумму для будущих шагов
            prefixSumCount[currentSum] =
                prefixSumCount.getOrDefault(currentSum, 0) + 1
        }

        return count
    }
}
```

## Детальный пример

**Вход:** `nums = [1, 2, 3]`, `k = 3`

| Шаг | num | currentSum | target = currentSum - k | map до обновления | Действие                      | count |
|-----|-----|------------|-------------------------|-------------------|-------------------------------|-------|
| –   | –   | –          | –                       | {0:1}             | –                             | 0     |
| 1   | 1   | 1          | -2                      | {0:1}             | -2 нет, добавляем 1:1         | 0     |
| 2   | 2   | 3          | 0                       | {0:1, 1:1}        | находим 0 → +1, добавляем 3:1 | 1     |
| 3   | 3   | 6          | 3                       | {0:1, 1:1, 3:1}   | находим 3 → +1, добавляем 6:1 | 2     |

**Ответ:** 2 (подмассивы: `[1,2]` и `[3]`).

---

## Что важно запомнить

- Словарь хранит **количество** появлений каждой префиксной суммы.
- Мы **не храним индексы**, только количества – этого достаточно для подсчёта
  числа подмассивов.
- Инициализация `{0:1}` критична: она позволяет учитывать подмассивы,
  начинающиеся с индекса 0.
- На каждом шаге мы сначала **проверяем**, потом **добавляем** текущую сумму.
  Это гарантирует, что мы не учтём пустой подмассив (когда `j = i`).
