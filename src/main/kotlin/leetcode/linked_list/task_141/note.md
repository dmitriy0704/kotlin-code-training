# 141. Linked List Cycle

## Условие

Дано имя head связанного списка. Определите, содержит ли связанный список цикл.

Цикл в связанном списке возникает, если в списке есть узел, до которого можно
снова добраться, непрерывно следуя указателю next. Внутри системы pos
используется для обозначения индекса узла, к которому подключен указатель next
указателя tail. Обратите внимание, что pos не передается в качестве параметра.

Возвращает true, если в связанном списке есть цикл. В противном случае
возвращает false.

Example 1:

```text
[3] ---> [2] ---> [0] ---> [-4]
          ^                 |
          |_________________|

```

Input: head = [3,2,0,-4], pos = 1
Output: true
Explanation: В связанном списке существует цикл, в котором хвост соединяется с
первым узлом (с индексом 0).

Example 2:

Input: head = [1,2], pos = 0
Output: true
Explanation: В связанном списке существует цикл, в котором хвост соединяется с
нулевым узлом.

Example 3:

Input: head = [1], pos = -1
Output: false
Explanation: There is no cycle in the linked list.

## Решение:

Самый эффективный способ решить эту задачу — использовать алгоритм поиска цикла
Флойда. (theory.md)
Представь двух бегунов на стадионе:

- Черепаха (slow) — двигается медленно, на 1 шаг за раз.
- Заяц (fast) — двигается быстро, на 2 шага за раз.

Если дорога прямая (цикла нет), Заяц первым добежит до конца (дойдет до null), и
мы поймем, что цикла нет.
Если есть круг (цикл), Заяц начнет бегать по кругу и рано или поздно догонит
Черепаху сзади. Они окажутся на одном и том же узле.

## Код

```kotlin
class ListNode(var `val`: Int) {
    var next: ListNode? = null
}

class Solution {
    fun hasCycle(head: ListNode?): Boolean {
        // Если список пустой или в нем один элемент, цикла быть не может
        if (head == null || head.next == null) {
            return false
        }

        var slow = head
        var fast = head

        // Бежим, пока Заяц не упрется в конец списка
        while (fast != null && fast.next != null) {
            slow = slow?.next       // Черепаха делает 1 шаг
            fast = fast.next?.next  // Заяц делает 2 шага

            // Если они встретились — цикл обнаружен
            if (slow == fast) {
                return true
            }
        }

        // Если Заяц дошел до конца — цикла нет
        return false
    }
}

```

## Сложность алгоритма

- Времени: O(N) — в худшем случае мы пройдем по элементам списка один или два
  раза.
- Памяти: O(1) — мы не создаем новых структур данных, а используем только
  два указателя.
