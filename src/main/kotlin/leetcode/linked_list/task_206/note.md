# 206. Reverse Linked List

## Условие

Имея в начале односвязный список, переверните список и верните перевернутый
список.

Example 1:
Input: head = [1,2,3,4,5]
Output: [5,4,3,2,1]

Example 2:
Input: head = [1,2]
Output: [2,1]

## Решение

Суть задачи

Тебе дается голова связного списка: 1 -> 2 -> 3 -> 4 -> 5 -> null.
Нужно развернуть все стрелки в противоположную сторону, чтобы получилось:
5 -> 4 -> 3 -> 2 -> 1 -> null.
Главная сложность — не потерять элементы в памяти в процессе разворота. Если ты
просто возьмешь узел 2 и направишь его next на 1, ты мгновенно потеряешь ссылку
на узел 3, и вся оставшаяся часть списка (3 -> 4 -> 5) сотрется из памяти
(Garbage Collector ее удалит).

Визуализация алгоритма (Три указателя)

Чтобы не терять узлы, нам понадобятся три переменные-указателя, которые будут
двигаться по списку:

1. prev (предыдущий) — куда должна указывать стрелка текущего узла.
2. current (текущий) — узел, чью стрелку мы разворачиваем прямо сейчас.
3. nextTmp (следующий/временный) — страховка, которая держит ссылку на
   оставшуюся часть списка.

Представь, что мы находимся в середине процесса на узле 2:

```text
  1 <- 2     3 -> 4 -> 5 -> null
  ^    ^     ^

  |    |     |
prev  curr  nextTmp

```

Мы временно запоминаем 3 в nextTmp. После этого мы можем безопасно развернуть
стрелку у 2 (направить её на 1). Затем мы просто сдвигаем prev и curr на один
шаг вправо.

## Код. Итеративный подход

Вот самое оптимальное решение, которое работает за \(O(N)\) по времени и тратит
O(1) памяти:

```kotlin
class Solution {
    fun reverseList(head: ListNode?): ListNode? {
        var prev: ListNode? = null
        var current = head

        while (current != null) {
            // 1. Страхуемся: запоминаем хвост (например, 3)
            val nextTmp = current.next

            // 2. РАЗВОРОТ: направляем стрелку назад (2 -> 1)
            current.next = prev

            // 3. Шаг вперед для prev (становится на 2)
            prev = current
            // 4. Шаг вперед для current (переходит на 3)
            current = nextTmp
        }

        // В конце current станет null, а prev будет стоять на бывшем последнем узле (новой голове)
        return prev
    }
}

```

## Пошаговый разбор на примере 1 -> 2 -> 3 -> null

Старт: prev = null, current = 1.

* Итерация 1 (работаем с узлом 1):

    1. nextTmp запоминает узел 2.
    2. current.next (узел 1) направляется на prev (null). Теперь первая связь
       оборвана: 1 -> null.
    3. prev сдвигается на узел 1.
    4. current переходит на nextTmp (узел 2).

* Итерация 2 (работаем с узлом 2):

    1. nextTmp запоминает узел 3.
    2. current.next (узел 2) направляется на prev (узел 1). Получилось: 2 ->
       1 -> null.
    3. prev сдвигается на узел 2.
    4. current переходит на nextTmp (узел 3).

* Итерация 3 (работаем с узлом 3):

    1. nextTmp запоминает null (конец исходного списка).
    2. current.next (узел 3) направляется на prev (узел 2). Получилось: 3 ->
       2 -> 1 -> null.
    3. prev сдвигается на узел 3.
    4. current становится null.

Конец цикла. Метод возвращает prev (узел 3), который теперь является новой 
головой развернутого списка.


Эту задачу также можно решить через рекурсию, но итеративный способ (через
while) считается более безопасным для продакшена, так как не переполняет стек
вызовов памяти.
