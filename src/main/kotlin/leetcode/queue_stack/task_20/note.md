# 20. Valid Parentheses

## Условие

Дана строка s, содержащая только символы '(', ')', '{', '}', '[' и ']'.
Определите, является ли входная строка допустимой.

Входная строка считается допустимой, если:

1. Открывающие скобки должны закрываться скобками того же типа.
2. Открывающие скобки должны закрываться в правильном порядке.
3. Каждой закрывающей скобке соответствует открывающая скобка того же типа.

Example 1:
Input: s = "()"
Output: true

Example 2:
Input: s = "()[]{}"
Output: true

Example 3:
Input: s = "(]"
Output: false

Example 4:
Input: s = "([])"
Output: true

Example 5:
Input: s = "([)]"
Output: false

## Решение

Задача 20. Valid Parentheses (Правильные скобки) — это фундаментальная задача
уровня Easy, которая идеально объясняет работу структуры данных Стек (Stack).

## 🎯 Суть задачи

Тебе дана строка s, содержащая только символы скобок: (, ), {, }, [ и ].
Нужно определить, является ли строка валидной.
Строка валидна, если:

1. Открытые скобки закрываются скобками того же типа.
2. Скобки закрываются в правильном порядке (например, ([)] — невалидно, а ([]) —
   валидно).
3. Каждой закрывающей скобке соответствует открывающая скобка того же типа.


## Суть решения: Структура данных Стек (Stack)

Стек работает по принципу LIFO (Last In, First Out — «последним пришел, первым
ушел»). Представь стопку тарелок: ты кладешь новую тарелку наверх и снять можешь
только самую верхнюю тарелку.
В этой задаче стек выполняет роль памяти «ожидания»:

1. Мы идем по строке слева направо.
2. Если мы видим открывающую скобку ( (, [, { ), мы «жадно» кладем её в стек.
3. Если мы видим закрывающую скобку (например, )), это означает, что она должна
   закрыть скобку, которая легла в стек самой последней.

* Мы достаем верхний элемент из стека.
    * Если стек оказался пустым (нет пары) ИЛИ скобка из стека не совпадает по
      типу (например, достали [, а текущая )), то строка невалидна.

4. В самом конце, после проверки всей строки, стек обязан остаться пустым. Если
   в нем что-то осталось (например, для строки ((), значит, какие-то скобки не
   закрылись.


## Код на Kotlin

Для реализации стека в Kotlin удобнее всего использовать класс ArrayDeque (он
работает быстрее, чем старый Java-класс Stack):

```kotlin
class Solution {
    fun isValid(s: String): Boolean {
// Создаем стек для хранения открывающих скобок
        val stack = ArrayDeque<Char>()

        for (char in s) {
            when (char) {
                // Если скобка открывающая — кладем в стек
                '(', '[', '{' -> stack.addLast(char)

                // Если закрывающая — проверяем пару
                ')' -> {
                    if (stack.isEmpty() || stack.removeLast() != '(') return false
                }
                ']' -> {
                    if (stack.isEmpty() || stack.removeLast() != '[') return false
                }
                '}' -> {
                    if (stack.isEmpty() || stack.removeLast() != '{') return false
                }
            }
        }

        // Строка валидна только если все открытые скобки нашли свою закрывающую пару
        return stack.isEmpty()
    }
}

```


## 🏃 Пошаговый разбор на примере: s = "()[]{}"

1. char = '(': открывающая. Кладем в стек. Стек: ['('].
2. char = ')': закрывающая. Стек не пустой, удаляем последний элемент из
   стека ('('). Проверяем: '(' == '('? Да. Пара совпала. Стек снова пустой: [].
3. char = '[': открывающая. Кладем в стек. Стек: ['['].
4. char = ']': закрывающая. Достаем из стека элемент ('['). Пара совпала.
   Стек: [].
5. char = '{': открывающая. Кладем в стек. Стек: ['{'].
6. char = '}': закрывающая. Достаем из стека элемент ('{'). Пара совпала.
   Стек: [].

Цикл завершился. Метод stack.isEmpty() возвращает true. Ответ: строка валидна!

## Сложность

* Времени: O(N) — мы делаем ровно один проход по строке длиной N. Операции
  добавления и удаления из конца ArrayDeque занимают стабильное время O(1).
* Памяти: O(N) — в худшем случае (если строка состоит только из открывающих
  скобок, например ((((), нам придется сохранить все N символов в стек.
